今天最集中的变化是价格。OpenAI 发布 GPT-6.2 Astra 与 Sol，微软在 Ignite 2026 一次推出七款模型，两家都把"每次任务花多少钱"写成了主要卖点。同一天，英伟达确认不再对华销售 H200，美国商务部把海外算力租用纳入许可，Anthropic 的上市文件把 1.5 万亿美元估值摆上台面。能力之外，算力与资本的可获得性正在重新定价。

## 主题一：GPT-6.2 更便宜，也更难被看清

OpenAI 发布面向复杂专业工作的 GPT-6.2 Astra 和面向日常任务的 GPT-6.2 Sol，同时上线 ChatGPT、Codex 与 API。官方口径是"用更少的输出 token 得到更好的结果"。真正有比较价值的是价格：OpenRouter 列出的价格是 Astra 每百万输入 8 美元、输出 40 美元，Sol 为 2 美元和 10 美元，两者都有 Pro 版本。

第三方基准给出的性价比更激进。Perplexity 称在其 WANDR 基准上 Astra 得分 0.783、单任务约 12.54 美元，比 GPT-6 Astra 高 0.095；Sol 得分 0.746、约 2.65 美元。测试者 @Yuchenj_UW 引述的数据是 Astra 在 Agents' Last Exam 1.1 上比 Claude Fable 5.2 高 5.5 分，成本只有对方的 5%。

但早期使用者的评价和榜单相反。Theo 称 Astra 是 OpenAI 发布过最糟糕的模型，Matt Shumer 表示基本无法使用；卡兹克在自己的小评测集里看到代码审查找出问题的比例从 GPT-6.1 Sol 的 65% 升到 Sol 的 84%、Astra 的 96%，代价是 Astra 慢一倍、贵四倍。@echen 的 staff 级编码榜上，两款新模型排第四和第五，仍落后最新 Claude。

一处容易被忽略的细节来自模型卡：在相近推理强度下，两款模型"使用了更少的推理 token，并且在非对抗评测中比此前模型更难监控"。少 token 是成本优势，难监控是审计代价，这两件事来自同一处设计。

也有相反方向的数据。测试者 @Hesamation 称 Astra 在 ARC-AGI-3 上拿到 100%，而该基准八个月前发布时没有任何模型超过 1%。这是单条转述，没有官方评测说明，只能当作待核实的信号，不足以推翻使用者的负面体验。

## 主题二：微软把"性价比"做成了产品线

Ignite 2026 上，微软 MAI 一次发布七款模型，主题是"可扩展的价格性能比"。其中 MAI Code 2 与 Code 2 Flash 面向企业日常编码，官方给出的数字是：四项基准平均达到 GPT 6.1 Sol 的 98% 性能、成本 40%；达到 Claude Opus 5.5 的 96% 性能、成本 5%；盲测前端评审中 64% 的情况下胜过 GPT-6 Sol。

语音侧发布首个语音到语音模型 MAI Realtime 1，起步价每分钟音频 0.01 美元，微软称其在 Big Bench Audio 与 τ-Voice 上于质量、速度和价格三项超过 GPT Realtime 2.1。图像侧 MAI-Image-2.7 称重回 Artificial Analysis 榜首，2.7-flash 定位成本与质量之间的新折中点。

比单个模型更值得看的是交付方式：MAI Licensed Weights 允许客户定制权重后运行在自己的 Azure 环境里，自己掌控权重与数据。这不是 API 调用，而是把模型当作可授权资产交付。同场还发布了 Copilot 新形态、Microsoft IQ、Agent 365 与 Cobalt 200 虚拟机。

这些数字全部来自微软自述，没有第三方复现。价格战的真实效果，要等企业把工作负载迁过去之后才能看到。Copilot 一侧的表述也值得记下：微软称 Word、Excel 与 PowerPoint 已经成为 Copilot 体验的一部分，Copilot 同时嵌入这些已有软件，方向不是用 agent 替换应用，而是让两者互相嵌进去。

## 主题四：英伟达同一天失去中国市场与 CEO

代理 CEO Colette Kress 表示，英伟达将不再在中国销售 H200 芯片，结束此前由黄仁勋与特朗普政府斡旋、需经美国境内并缴纳 25% 关税的出口通道。TechCrunch 引述的影响区间是 44 亿至 62 亿美元收入。董事会同时成立国家安全与出口管制监督委员会，原有的国家安全团队和全球贸易合规团队直接向该委员会与代理 CEO 汇报，并引入外部法律与贸易合规专家。

财报数字依然强劲：第三财季营收 1158 亿美元，同比增长 103%；数据中心收入 1076 亿美元，占 93%；季度利润 653 亿美元，翻倍。数据中心占比越高，中国销售的剥离对当期总收入的稀释就越小，但不确定性转移到了"海外算力"那一侧。

治理压力没有缓解。董事会此前已就"黄仁勋可能成为外国情报行动目标"的报道启动独立调查，美国国会也开始介入对华芯片出口问题。围绕他是否回归，特朗普表示不反对，财政部长贝森特倾向从外部找人，一份公开信收集到超过 15 万个签名，周一股价再跌 4%。

WSJ 还报道，SEC 正以民事调查核实英伟达的披露是否误导投资者，焦点之一是公司自 2025 年 7 月止季度后停止单列新加坡收入——该季度新加坡账单达 102 亿美元、占总数的 22%。黄仁勋随后发布声明，承认个人生活中的严重错误给董事会造成麻烦，承诺配合独立调查，并称若董事会认为回归符合股东、员工、公司与美国的最佳利益，他愿意回到 CEO 岗位。董事会此前表示不考虑其回归。

对这套增长机器的另一种解读来自 Ed Zitron：他认为 AI 泡沫实质是英伟达泡沫，靠循环融资、渠道压货和围绕出口管制的争议交易维持，创始人离开后这套模式难以为继。这是评论而不是审计结论，但它列出的三条机制，可以拿去对照财报里的应收账款与库存变化。

## 主题六：一个在内核，一个在供应链

OpenJDK 关键漏洞 CVE-2026-114938（Java4Shell）CVSSv4 评分 9.2，成因是 AVX-512 Base64 解码的汇编代码在处理结尾填充字符时，输出数组的边界计算发生下溢，造成堆内存越界写入。Wiz 已证实可对 Jenkins、Confluence、Apache Tomcat 等实现远程利用，并给出了检测命令与 JVM 缓解参数。OpenAI 的 Greg Brockman 在 X 上把该漏洞的发现与公司的 Patch the Planet 计划联系起来，这一关联尚未被独立确认。

同一天还有一起供应链投毒。PyPI 上的 agent-framework 出现 1.26.1 和 1.26.2 两个恶意版本，植入的 .pth 文件会在 Python 启动时运行凭据窃取器，收集环境变量、凭据文件以及 Azure 与 Azure DevOps 的托管标识和 OIDC 令牌，回传至 webhook.site。恶意版本上传当日约 21:30 UTC 后已下架。

两起事件的处置节奏不同。前者需要先盘清哪些服务暴露在受影响的 JVM 上，再打补丁或加缓解参数；后者要求假定凭据已泄露，直接轮换并检查 CI 流水线的出网行为。

## 主题八：实测结果把瓶颈指到委派与验证

SWE-CoWork 把智能体放进模拟团队：有工单、有文档、有可以提问的同事，最终要交付能通过隐藏测试的补丁，横跨 101 个真实仓库。结果是表现最好的模型只完整完成了 8 个任务；对 Claude Opus 5.5 而言，超过一半的失败发生在它已经拿到需求之后。

委派链上的失真更明显。一项覆盖 18 款模型的研究在文件库里植入伪造记录：强模型自行检索时，千余次试验几乎没有产生有害修改；一旦把检索委派给廉价子代理，五个聚合器在 751/757 次试验中复现了被污染子代理的错误。

Google 的 RSI 论文走的是另一条路：不只改模型，而是自动改进 agent 的外层 harness，并配一套自改进记忆，记录每次编辑的理由、预测结果、实际结果和评测上下文。十个连续运行里有九个改善，十次编码运行平均提升 2.36 分（p=0.003）。但换模型会失效：一个由 Opus 演化出的 harness 迁移到 Gemini 上只从 68.41 起步，低于朴素种子 harness 的 73.89。

方法层面的结论比分数更有用：修改定位任务用分层代码图（系统／包与架构模块两级依赖）能把相对 F1 提升 15.6% 到 86.2%，但这只覆盖"改哪里"，不等于修复成功率。

另外两组结果说明基础能力仍在推进。Agentic-OPD 把最佳验证检查点当作学生、其余已保存检查点当作冻结教师，按能力缺口选择指导，避免蒸馏覆盖已掌握的行为；在五类智能体任务、24 个基准上，相对初始化检查点最高提升 7.4 分，4B 学生在深度搜索测试里超过了文中列出的 GPT-5.6 与 DeepSeek-V4.1。CMU 的评测则让 Opus 5.5 配合 Claude Code 完成预训练流水线、推理引擎、集群编排等六项基建任务，奇点指数 1.25，人类工具基线设为 1.0——这是特定评测，不等于系统已具备通用能力。

生成已经不是主要瓶颈，验证和委派才是。

评估机制本身也在调整。OpenAI 与四家独立机构签署协议，允许其接触部分内部系统和数据，评估模型行为、训练与防护措施；发帖者进一步猜测这与 GPT-6.2 延期有关，材料没有证实这层关联。另一组数字来自 ChatGPT for Academic Researchers：项目覆盖逾 1800 名参与者，自报生产效率接近翻倍，这是参与者主观报告，不是统一任务下的客观测量。

## 主题十：智能体工程开始围绕验证组织

Claude Code 推出实验性 Code Mode：Claude 不再逐个调用工具，而是写脚本把多个工具串起来，并且能在长命令仍在运行时回复用户。开关是一个环境变量 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1。

Claude Code 团队公开的做法是把验证当成交付物：团队 90% 的代码由 Claude 编写并审查，真正限制并行规模的是验证带宽，因此重点投入端到端测试、属性测试和差分测试三类验证。Anthropic 工程师 Vivek Nair 复盘 Claude Docs 上线前的 chaos loop：在镜像生产的 staging 集群上每天压入超过 100 万份合成文档，峰值同时运行 30 个 sub-agent，最终 20 亿次请求只出现 60 次服务器错误。

腾讯把同类思路做成了开源框架 LoopForge，把分工、测试、评审和返工写进流程，再用评测反过来改流程。

角色分离还有另一种做法。华为论文中的 EvoTrias 把规划、编码与评分交给三个独立角色，编码代理接触不到评分器；据帖文转述，七项数学任务里领先六项，单次运行 token 成本比四代理的 CORAL 低 64%，300 个 OR-Tools 实例上求解质量提升 13.2%。Together 团队的做法更朴素：用 coding agent 去测自家 SDK、命令行和文档，结论是失败的不只是模型，文档和技能包同样有问题。

推理侧也在重组。SGLang 成立联盟，创始成员包括 NVIDIA、AMD、Intel、Google、Meta、Thinking Machines Lab、Cloudflare、Modal 和 RadixArk；联盟公告引用 Deloitte 数据称 2026 年推理将占全部 AI 算力的三分之二。SGLang 同期发布 v1.0，关键路径用 Rust 重写，已有 330 多家机构在用、217 个模型支持 Day-0。

## 编辑结论

今天所有重要变化都可以换算成同一个问题：单位任务多少钱、由谁保证结果可信。OpenAI 与微软把价格压到对手的零头，代价是模型行为更难被审查；英伟达与出口管制把算力的可获得性收紧；Anthropic 的上市文件则说明，即便营收增长极快，算力成本仍是决定利润的那一项。真正稀缺的不再是生成能力，而是能验证生成结果的流程。
