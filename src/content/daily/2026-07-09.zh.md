# 2026-07-09 PT AI 日报：OpenAI 与 SpaceXAI 同日交付，Meta 33 亿用户起跑

PT 7-09 一天之内三家旗舰同时落地：OpenAI 把 GPT-5.6 推到 Microsoft 365 Copilot 的 preferred 位置并上线 ChatGPT Work；xAI/SpaceXAI 携 Grok 4.5 正式登陆 Cursor 联合训练席位；Meta 把 Muse Spark 1.1 推到 33 亿用户的 WhatsApp/Instagram/Meta AI。**当日的核心判断是：模型层"重量级迭代 + 终端用户体量"组合第一次同时压上，规模竞赛从"声明"切换为"出货"**。

## 主题一：OpenAI 一日四发，Codex 升级为 ChatGPT Work

OpenAI 7-09 同日落地 4 个发布（openai-blog.md RSS 4 篇真新文已确认）：GPT-5.6 正式上线、ChatGPT Work 作为 Codex 升级版（每周 Codex 用户 500 万 + 其中 100 万非编程场景）、Bio Bug Bounty 项目、Microsoft 365 Copilot 切换为 GPT-5.6 preferred（覆盖 Word/Excel/PPT/Chat/Cowork）。Codex 桌面应用合并进新 ChatGPT 桌面，Free 用户也能用 Chat/Work/Codex 三模式。

**值得记下的是，Codex 升级 Work 的命名变化比产品本身更值得关注——OpenAI 把"为开发者"的 Codex 包装成"为所有长期任务"的通用 agent，宣告"编程 agent"作为独立 SKU 让位给"任务 agent"**。Codex 在 7-08 daily 主题一（Codex/GPT-Live 预告）已经展开，7-09 的核心增量是"产品线跃迁 + Microsoft 365 同步切换"——这是企业采购信号，不是模型信号。

## 主题二：Grok 4.5 正式交付，1.5T 参数 + 25% Opus 价格 + 80 tok/s

xAI/SpaceXAI 把 Grok 4.5 推到 public launch，Cursor 联合训练席位。Artificial Analysis 评分 54（#4，落后 Fable 5 / GPT-5.5 / Opus 4.8），但**关键指标是 token 效率**：Intelligence Index 任务 $0.31、GDPval $0.49、Coding Agent Index $2.59；平均输出 token 14k（比 Opus 4.8 少 60%），总 token 1.9M（比 Fable 5 的 7.2M 和 GPT-5.5 的 6.2M 显著低）。官方定价 $2/$6 每百万 token，Cache hit 折扣 75% 到 $0.5，500k context 窗口（可能回升到 1M）。

**Grok 4.5 的"Opus 级 + 25% 价格 + 80 tok/s + 60% 少 token"组合是成本结构的根本性重写——不是性能更好，是同等性能下成本结构崩塌**。Cursor 第一周 double usage 配额、Codex/Amp/Hermes Agent/OpenRouter day-0 上线，证明这是 product-market fit 而非 benchmark 宣传。Musk 公开承认 Grok 4.5 "是 Opus 级但更快"——这是 xAI 第一次明确放弃 benchmark 冠军叙事、转向"性价比 + agent 优化"叙事。

**与同日 top-story 候选的差异**：7-08 daily 主题三已写过 Grok 4.5（发布日 + 价格），7-09 的核心增量是 ainews-substack 整篇 11.5KB 的 AI News 综述（Artificial Analysis 全部指标 + Cursor 联合训练机制 + 25% Opus 价格含义），机制层细节更厚。**但本主题在 daily.md 主体里只点不展开**——完整分析留给 top-story 候选池的更独立主题。

## 主题三：Meta Muse Spark 1.1 33 亿用户直推，3 榜 Agent SOTA + 比 Fable 5 便宜 10x

Meta 把 Muse Spark 1.1（agentic + coding 模型）通过 Meta AI / Instagram / WhatsApp 推到 **33 亿月活用户**——这是 7-09 当天最值得记的产业级结构变化。ValsAI 实测显示（X 池 @Lonely__MH ❤️4 🔁1 评论 7 / @KanikaBK ❤️3 🔁2 / @garrytan 1.0K RT），Muse Spark 1.1 直接刷新医疗（MedScribe）、税务（TaxEval）、法律 Agent 三个榜单 SOTA，**比 Fable 5 便宜 10 倍、快 2 倍**。Finkd（Mark Zuckerberg）官方发布帖明确说"very low price"。

**Muse Spark 1.1 不只是又一个模型——它是"33 亿用户体量 + 专业 Agent 榜单 SOTA + 比闭源旗舰便宜 10x"的组合拳**。上一次同等组合是 ChatGPT 4o 发布（5 亿用户 + 多模态），但 4o 的 5 亿是 web 端 + iOS 端，**没有 Instagram/WhatsApp 这种"在用户日常通讯流里"的渗透路径**。Meta Superintelligence Labs 4-7 周前才成立（7-07 daily 主题二），6 周后就能交付 33 亿用户体量的 agentic 模型 + 3 榜 SOTA，**意味着"AI 实验室 → 终端用户"的传统 18-24 个月路径被压缩到 6-8 周**。

## 主题四：3 万亿 vs 1.5 万亿，AI 基础设施回本缺口

Sequoia 合伙人 David Cahn 更新 2026 年全球 AI 基础设施支出估算到 **1.5 万亿美元**，按当前商业化节奏，行业需产生 **3 万亿美元收入才能回本**。Anthropic ARR 600 亿、OpenAI 2025 年收入 130 亿（11 月称 ARR 200 亿），缺口仍大。Apollo 首席经济学家补充：超大规模厂商 2028 年自由现金流加速目标面临两个反向压力——更多组织转向便宜的开源权重模型（尤其中国模型）+ OpenAI 编码任务 token 效率提升 54% 持续压低 token 价格。

**这不只是"AI 是否赚钱"的宏观争论——它是"模型层 + harness 层 + 终端体量"三方博弈的具体数字**。Cahn 的 3 万亿对应 5 家超大规模厂商（Google/Meta/Microsoft/Amazon + Anthropic/OpenAI）的现金流回正需求，Anthropic 600 亿 ARR 意味着要 50 倍才能填上缺口——按 Sequoia 模型，需要的不是模型层涨价，而是"用 AI 替代人力成本"的速度超过 token 单价下降速度。Apollo 的"开源权重 + token 效率"两个反向压力同时出现，**意味着 3 万亿缺口可能不是靠收入增长解决，而是靠成本结构再压一轮**。

## 主题六：Google SensorFM 可穿戴健康基础模型，100 万亿分钟传感器数据

Google Research 发布 SensorFM（`https://research.google/blog/sensorfm-towards-a-general-intelligence-and-interface-for-wearable-health-data`），一个在 **100 万亿分钟**多模态传感器数据上预训练的通用基础模型，数据来自 500 万参与者，覆盖 100+ 国家、20+ Fitbit/Pixel Watch 设备。SensorFM 学习通用人体生理表征，可迁移至心血管、代谢、睡眠、心理健康、生活方式等 **35 项**健康预测任务，支持标签高效适配 + 数据填充，可作为个人健康 agent 的基础工具。

**SensorFM 的产业含义是"垂直基础模型"作为基础设施层第一次具备严肃规模**——100 万亿分钟数据 = 190 万年连续传感信号 = 单一公司难以复制的规模。35 项预测任务覆盖 = 不是单一终点模型，是"健康领域的 GPT-1 时刻"。对 Apple Health（自研垂直）、Oura Ring（垂直数据）、传统医疗 AI（按病种训练）的冲击是结构性的：**单一公司训练的通用基础模型首次具备跨设备、跨人群、跨任务的可迁移性**。

## 主题七：蚂蚁灵波 LingBot-Video — 具身智能首个 MoE 视频基模

蚂蚁灵波开源 **LingBot-Video**（`https://www.ithome.com/0/974/517.htm`），**全球首个基于 MoE 架构、面向具身智能的视频生成基础模型**。总参数 30B，推理时仅激活约 3B，效率较同规模 Dense 架构提升约 3 倍。模型引入 7 万小时 VLA/VLN/Ego 等机器人数据，通过多维强化学习奖励系统对齐物理合理性与任务完成度。RBench 总分 0.620（超 Wan2.6），Physics-IQ Verified 评测第一。

**这是中国 AI 在"具身智能 + 视频生成"交叉点的第一次基础设施级输出**。7 万小时机器人专属数据（VLA 视觉-语言-动作、VLN 视觉-语言-导航、Ego 第一人称）是蚂蚁灵波的核心壁垒——30B/3B 激活的 MoE 架构让"具身视频基模"从"实验室"走到"开源可下载"，意味着学术和中小公司可以基于它做下游具身策略。**与同日 Seedream 5.0 Pro（字节图片）、Seedance 2.5 Pro（字节视频）的产品级输出不同**，LingBot-Video 是"基础模型"层输出，**对标的是 NVIDIA Cosmos / Genie-2 / Sora 这类研究级视频基模**。
