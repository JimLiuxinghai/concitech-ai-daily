## 主题一：英伟达董事会接近决定是否换掉创始人

《华尔街日报》报道，英伟达董事会此前在周日公开支持黄仁勋，如今接近决定是否罢免这位创始人 CEO，并可能很快开会。触发点是黄仁勋与一名被指为中国情报人员的女子交往，随后又曝出与公司一名副总裁的第二段关系。纽约时报的相关报道出来后，英伟达盘后一度下跌约 8%。

压力来自多个方向。路透社报道一所与中国军方关系密切的中国大学购入了英伟达 H200 芯片；国会共和党人已就此事致函，黄仁勋尚未回应。The Economist 刊出"黄仁勋必须离开"的评论，Garry Tan 则公开反对，认为换帅会让市值崩塌。市场还在追问另一件具体的事：英伟达此前承诺给 Anthropic 的 100 亿美元投资是否照付。

这里的证据边界很清楚。董事会是否罢免、何时表决，目前都只有媒体转述，没有公司公告；盘后跌幅属于交易时段外的价格反应，不等于股东投票结果。可以确认的是，一场围绕创始人个人行为的风波，已经升级为对一家市值最高公司治理结构的公开质疑。

## 主题二：Anthropic 的 IPO 已获数倍超额认购

彭博社报道，Anthropic 的 IPO 已收到数倍于发行份额的订单，主要来自大型机构的锚定级意向。公司通过 IPO 加私募配售寻求最高 904 亿美元，将超过 SpaceX 的 857 亿美元纪录；完全稀释估值目标约 1.4 万亿美元，由高盛和摩根士丹利牵头共 22 家银行承销，代码 ANT，在纳斯达克全球精选市场交易。

腾讯科技的报道给出了另一套口径：拟发行 8.25 亿股，每股 70 至 78 美元，按发行后股本计算估值上限约 1.02 万亿美元。两个数字并不矛盾，1.02 万亿对应发行后股本，1.4 万亿把潜在股份一并算入完全摊薄。引用时要说清用的是哪一套。

同一批信息里还有一条容易被忽略的细节：Anthropic 与 SpaceX 的算力租约据称将在 2027 年年中结束。有分析认为主动方可能是 SpaceX，理由是 Grok 新模型间隔过长、缺少不同规模的模型家族，算力本身吃紧。这与 IPO 文件里"AI 可能大幅加速自身研究"的警告放在一起看，说明算力约束正在从成本问题变成竞争节奏问题。

资本效率这一侧，同一天还有一组对照数字。据《华尔街日报》和 The Information 报道，OpenAI 第三季度营收环比增长约 50% 至 100 亿美元，调整后经营亏损则从 101 亿美元扩大到 109 亿美元。报道的判断是：企业销售确实把收入推上去了，但单位收入的亏损没有收窄，效率仍落后于 Anthropic。把这组数字和 Anthropic 的万亿估值放在一起，能看出当前定价买的不是当期利润，而是对"谁先跑到下一阶段"的下注。

需要保留的不确定性是：以上均为拟议发行安排和媒体报道，不等于已经完成上市或募资；估值倍数、超额认购倍数都有多种统计口径；算力租约的终止方向目前只是外部推测，两家公司都没有确认。

## 主题三：METR 的十一周驻场，让 AI 2027 作者改了口径

AI Valley 汇总的一则进展值得单独摆出来。METR 在 Anthropic 内部驻场十一周后估计，这家公司的 AI 进展速度约为其历史节奏的两倍，其中可能有 80% 的加速来自 AI 本身。AI 2027 的六位作者据此认为，现实比他们的原始情景提前了约五个月。

具体到个人判断：Daniel Kokotajlo 把"超人类 AI 研究者"出现的时间从三个月前给出的 2028 年 12 月，提前到 2027 年 5 月的五五开。他的原话是"我害怕、悲伤、愤怒"。团队的模型还给出两个更远的推演：2027 年一年可能压缩进约五年的历史进展；2028 年前出现几乎在所有白领工作上超越顶尖人类专家的 AI，概率为 35% 至 65%。

证据边界必须写清楚。Anthropic 删节了 METR 依赖的大部分材料，样本只有一家公司，员工"效率提升 12 倍"属于自报数据。这是强信号，不是证明。真正让这份材料有分量的是它的来源：做长期预测的人自己被结果推翻了预期，而不是外部评论者事后归因。

同一天还有一条方法论上的呼应。《No Second Run》的作者报告把一次难以端到端复现的前沿预训练拆成多个可闭环优化的小环节，训练出 801-30B-A3B-Base 混合专家模型，并开放基础模型与轻量 SFT 数据。作者称这是首次完整报告贯穿前沿预训练的递归自我改进实践，"首次"是他们对自己研究位置的表述，不是第三方认定。

## 主题四：Agent 在四周内为 Signal 的加密代码写出数百万行证明

Google DeepMind 报告，研究人员引导智能体在四周内对 Signal 核心加密代码的指定安全属性完成形式化证明，全部由 Lean 检查。按外部转述的数字，由 Gemini 4 Carbon 驱动的 Agent 在未修改的 libsignal 代码上写了约 650 万行 Lean 证明，五人团队四周完成。

对照尺度的选择很关键。验证 seL4 微内核当年花了约 20 人年。团队还在隔离版本里重新植入了两个已修复的真实漏洞，系统都给出了对应不安全性的机器检查证明——这比"证明通过"更能说明流程不是走过场。

限制同样明确：成果针对专家指定的安全属性，不是对所有潜在缺陷的全面排除；人力投入、算力消耗和"650 万行"的统计方式在转述中没有完整披露。即便如此，这条信号的意义在于形式化验证的成本结构变了：规格仍由人写，证明由机器写，检查由证明器做。

值得注意的分工细节是：人类和 Agent 一起写安全规格，prover agent 写证明，Lean 逐条检查。规格这一步没有被自动化，也无法被自动化——"要证明什么"仍然是人的判断，这也是外部转述强调"专家指定属性"的原因。工程上可迁移的部分是流程，而不是数字。

## 主题五：Gemini Decisions API 把模型输出从文字改成概率

Google 发布 Gemini Decisions API，由新模型 Gemini Decision 1 驱动。它把同一份输入和最多 1000 道彼此独立的问题一起送进去，在一次推理里完成打分，返回校准后的概率和置信度，不生成任何文本，输出 token 恒为 0。端到端延迟 150 至 250 毫秒，输入可覆盖文本、图像、音频、视频和 PDF，上限 256K token。

问题的形式被限制在三类：判断是或否并给出"是"的概率、在固定选项里选一个、按有序等级打分。程序拿这些数字做路由、过滤或决定是否转人工，而不是等一段解释。价格是每百万输入 token 0.10 美元，不另收输出费，同一份共享输入只计一次；免费档每分钟 200 次请求、5 万 token，每天 1 万次，内容会用于改进产品。

这类接口真正替代的是自训分类器和规则引擎。过去要判"这条工单该不该转人工"，得自己标数据、训小模型、维护阈值；现在可以一次调用问 1000 个问题，只付输入的钱。代价是它只回答封闭式问题，需要理由或自定义结构时仍要回到生成接口——这个分工被写进了官方文档。

成本结构因此变化得比较彻底。输出 token 恒为 0，意味着账单只随输入长度增长，而同一份共享输入只计一次、各问题只追加自己的说明，这使得"一次请求里塞进上千个判断"在经济上可行。真正需要掂量的是校准质量：概率若不准，路由和过滤就会系统性偏向某一侧，而这类错误不会以报错的形式出现。

同一天 Databricks 发布了新版 Genie，声称在企业任务上达到 91%，准确率是两者中较强前沿 Agent 的 1.6 倍，token 消耗不到一半，核心是一个从数据、查询、看板和 notebook 里自动学习业务如何运作的 Genie Ontology 层。两家公司的方向一致：把"理解上下文"和"做出判断"拆成两层分别优化。

## 主题六：Grok 生成的应用里，94.7% 不需要登录就能打开

安全公司 Claroc 检查了 37,571 个仍在线的 Grok 构建应用，其中 35,578 个、约 94.7% 无需登录即可访问。机制并不复杂：发布对话框默认预选"任何拿到链接的人"，而每个应用的独立子域名会进入可检索的 passive DNS 数据库，于是"没公开"事实上等于公开。被读到的内容包括患者数据、明文密码，以及 SpaceXAI 自己的销售管线。

## 主题七：Runway 开源 27B 世界动作模型，机器人评测口径开始打架

Runway 把 Praxis-1 以 Apache 2.0 开放权重发布。这是一个 27B 参数的混合专家扩散 Transformer，同时预测视频与动作。在 NVIDIA RoboLab-120 榜单上，它报告 46.2% 的成功率，高于 FLUX 3 Action 的 42.9%、Cosmos3 Nano 的 36.8% 和 π0.5 的 28.0%。

同一天的机器人研究给出了另一组数字。AMP1 声称无需演示或任务专项训练，在 RoboLab-120 上取得 85.6%，十二项任务、三台机器人的 108 次真实试验成功 104 次。两个数字都自称同一个榜单，差距却接近一倍，说明任务子集、输入模态和成功判定并不统一——在原始评测设置公开之前，不该把它们放进同一张表比较。

工业侧的动作更具体。Gemini Robotics 2.5 在奔驰产线试点中，Apollo 2 抓取金属汽车支架并放入排序容器，成功率达到 96%，这是特定工业试验而非通用成功率。蚂蚁灵波用 4983 小时、13.3 亿帧真实触觉数据训练 LingBot-Touch，在冻结触觉模型、迁移到新磁触觉灵巧手的测试里，把 π0.5 的平均成功率从 48% 提到 74.17%。

另一条值得记录的发布方式来自 NVIDIA。Jim Fan 放出 GR00T 2 控制真实灵巧手完成化学实验并自行清理的完整视频，明确标注为无人剪辑、一倍速，并称后续会持续发布同类素材。模型本身是一个预测物理世界如何演变、再生成动作的世界动作模型，单个模型可覆盖平行夹爪、灵巧手和人形三种形态；帖子没有给出统一成功率，也没有与其他路线的完整对照。

三条路线分别押注开放权重、零样本通用策略和触觉数据迁移。共同点是证据都还停在"某一套设置下有效"，距离可复用的工程结论还有距离。评测口径不统一这件事，比任何单个成功率数字都更值得记住。

## 主题八：Agent 写的前端代码，一半过不了现代 Web 检查

Chrome 团队发布 Modern Web Guidance 1.0，把 200 多份 Web 平台指南做成编码 Agent 可加载的技能。配套评测给出的结论刺耳：无引导的前沿模型平均只通过约 50% 的检查项，加载指南后升到约 90%。另一组近 1000 次评测里，前沿模型自行通过率约 60%，引导后为 80% 至 90%。

失败集中在几个具体位置。自定义下拉框任务上，无引导模型得分 44%，引导后 92%——差距来自把原生 select 拆成 div 重写，丢掉 label、漏掉 name 属性、键盘导航失效。弹窗与浮层的进出场动画任务里，六次无引导运行中有五次没有使用现代 CSS 的进入退出属性，六次全部忽略了 prefers-reduced-motion。

原因被讲得很直白：模型从大量既有代码里学习，十年的旧写法压过最近十二个月的新标准。指南的做法是在写代码前加载专家条目，并要求 Agent 在回复末尾说明用了哪些指南、哪些 API、规避了什么问题。这套"解释选择"的设计，顺带把 Agent 变成了学习工具。

落地路径也不依赖 Agent。同一份指南可以用命令行工具检索、列举和读取，例如按"给弹窗遮罩做动画"这样的任务描述去搜条目；团队还可以在 AGENTS.md 或 CLAUDE.md 里写死浏览器支持目标，让 Agent 应用的降级方案与团队的兼容策略一致。每条指南都附带 Baseline 支持数据和对应降级写法，这比"要不要用新特性"的口头讨论更容易执行。

需要打折的地方是评测的归属：任务集和检查项都由指南自身定义，发布方同时是评测方，存在自评倾向；50% 与 90% 的对比也未给出模型分布。

## 主题九：用可穿戴数据算"可改变的健康年龄"，再用世界模型模拟十二周

Google Research 发布一套研究框架，把被动采集的可穿戴信号换算成一个可干预的健康年龄。模型只用四个核心信号：静息心率、每日步数、睡眠时长、每周 Active Zone Minutes，可选加入 VO2max、作息规律性和胰岛素抵抗。它对信号之间的重叠做了数学校正，输出的是健康年龄与真实年龄的差值。

第二个组件是 SensorWM，一个以动作为条件的世界模型，在约 10 万名 Fitbit 用户、228 万人周的数据上预训练。给定两周基线数据，它能预测 20 项生理指标在未来十二周内随步数、睡眠和运动安排如何变化，报告称优于 TimesFM 这类通用时序基础模型。

验证规模不小。All of Us 队列中 22,748 人、超过 6.8 万人年的随访显示，基线健康年龄高于真实年龄的人，八年间患高血压、心血管疾病或二型糖尿病的概率显著更高。在 5 名认证生活教练和 5 名医生的盲评中，反事实方案在 71.4% 的评估里被评为最佳，医生判定 99.2% 的方案在安全运动强度内、97.6% 的生理表述准确。

教练环节的设计值得单独说一句。系统为每个人模拟 125 组十二周习惯组合，再和"保持现状"的投影对比，然后用一个带可行性约束的优化器筛掉不现实的方案：基线习惯弹性高的人拿到更激进的目标，健康年龄可降约 2.3 岁；作息受限的人得到更平缓的节奏，约 1.3 岁。最后才由语言模型把排名靠前的路径写成循序渐进的计划。这个顺序很重要——先算可行性，再让模型措辞。

边界写得比较诚实：评估全部是回顾性、离线完成的，模型是研究原型而非临床诊断工具，尚未进入前瞻试验。这类工作真正的看点是"可干预"这个约束——所有输入都必须是能被日常选择改变的量，这恰好排除了大多数只预测出生年份的生理年龄模型。
