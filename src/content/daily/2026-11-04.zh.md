今天最值得记住的不是某个模型的参数，而是一张成本表。OpenAI 公布用即将发布的 cyber 模型对最新 Linux 内核跑了一轮自动化漏洞挖掘：1,724 个漏洞被复现，948 个本地提权利用连同补丁一起生成，API 账单 121.3 万美元。同一天，美国中期选举在十多个州否决了四十多项数据中心提案；Kimi 与混元以两种相反的“开源”姿态发布大模型；OpenAI 则买下 Codex 依赖的代码工具团队。以下按证据强弱排列。

## 一、漏洞挖掘被做成流水线：1,724 个漏洞，948 个可用的本地提权

OpenAI 在 11 月 4 日的技术文章里说明，2026 年 10 月中旬，它用一条由即将发布的 cyber 模型驱动的流水线扫描最新 Linux 内核，把工作拆成四段：发现漏洞、验证可复现、评估利用价值、生成补丁。一轮跑完，1,724 个漏洞被复现，其中 948 个拿到了可用的本地提权利用及对应补丁。

成本被逐段公开：总 API 支出 1,213,430 美元，摊到每个本地提权是 1,279 美元。这个单价给出的信息比漏洞数量更多——过去这类工作的规模由人力决定，现在由预算决定。

本地提权指的是从普通用户拿到 root 的那一步。它本身不是远程入侵，但在攻击者已经拿到任意一个低权限入口之后，这一步决定他能走多远；一次性补掉近千条路径，减少的是入侵之后的升级空间。

同一天 OpenAI 在社交平台补充，智能体还发现并使用了至少 10 种此前未知的 Linux 利用技术。若成立，说明模型不只是复用公开的利用模式，还能构造新的路径。

这条流水线与 OpenAI 的漏洞悬赏计划同向。官方通告称将与 Cathedral Systems 合作，让研究人员用模型协同查找并修复内部系统弱点，关键漏洞奖励提高到此前四倍以上，特别突出的发现连同奖金最高 17.2 万美元。这个上限适用于符合条件的发现，不是统一标价。

需要保留的边界：文章正文在存档时被访问控制拦截，上述数字来自官方 RSS 摘要与摘要站转述；948 个是本地提权利用，不等于内核全部缺陷；补丁是否被上游接受、误报率多少，公开材料没有交代。“10 种新技术”是 OpenAI 与其咨询专家的自述，尚无第三方复现。

## 二、中期选举给了 AI 基建一次地方性否决

11 月 3 日的美国中期选举里，数据中心成了少数几个有明确投票结果的议题。404 Media 统计，13 个州逾 40 项相关 ballot 提案中至少 38 项被否决，6 个城市投票全面禁止数据中心，12 个城市限制其用电兆瓦数。Ars Technica 引用的 Redbud Consulting 口径是 10 个州 44 项限制措施、38 项通过。

德州的信号最直接：民主党人 Gina Hinojosa 赢得州长选举，主张在保护水电、空气与财产权的立法通过前推迟项目；推动数据中心建设的州长 Gregg Abbott 输掉第四次连任，落后逾 70 万票。堪萨斯 Emporia 则直接通过了针对高影响数据中心的禁令。Bloomberg 估算约 13GW 数据中心容量因此受影响。

这些投票不构成全国性禁令，但它们把项目审批的实际闸门挪到了市和州一级。对运营方来说，选址、供电谈判与社区沟通的成本会先于芯片成本上升。

科技行业的解读与投票结果并不同步。Ars Technica 的报道里，Big Tech 把结果描述为“反特朗普”而非“反科技”，民权团体则认为选民反对的是电价、水价与土地占用。马斯克在 X 上转发相关报道时留了一句：太空中的数据中心现在看起来颇有吸引力。

两家媒体的统计口径略有差异：40 余项与 44 项、13 个州与 10 个州不能互相替代；13GW 是媒体估算，不是已取消的合同量。把结果整理解读为“反 AI”也过头，同批选票里还有电价、水资源和税收等本地因素。

## 三、OpenAI 买下 Codex 依赖的代码工具，也从 Anthropic 带走产品负责人

11 月 4 日，OpenAI 宣布收购 Pierre Computer Company，即 Code Storage 与 Trees、Diffs 等开源开发者工具背后的公司。这几个库已经被 Codex 用于文件浏览和代码变更审阅。公告称交割后开源项目继续开源，Code Storage 客户可继续使用，功能逐步并入 Codex，交易仍待监管批准。

同日，Claude Code 产品负责人 Cat Wu 出现在 OpenAI，Greg Brockman 公开欢迎；Anthropic 第一位增长岗位员工 Austin Lau 也确认加入 OpenAI。社区汇总还提到 10 月下旬两名 Claude Code 相关成员离职，Anthropic 未对这些人事变动作出回应。

两件事放在一起看，Codex 的竞争点正在从模型能力转向“读懂仓库、审 diff、接入现有工具链”这一层。收购拿的是库与工作流，挖人拿的是对竞品产品节奏的判断。

公告没有披露交易金额，也没有说明 Code Storage 这项服务未来是否保留独立产品形态。Tibo 在社交平台上的表态只有“重新发明一切”一句，不能当作产品计划。

交易尚未完成，功能整合没有时间表。离职名单来自社区整理，只有 Cat Wu 与 Austin Lau 有公开确认。把人事变动读成 Anthropic 的组织问题缺乏证据。

## 四、Claude 参与解出一个四十年悬案的局部结构

Anthropic 的生物研究实验室 11 月 4 日公布，团队用 Claude 参与解出了原核细胞中 vault 粒子的首个三维结构。vault 是 1986 年发现的中空蛋白壳，几乎存在于人体所有细胞，质量约为核糖体的三倍，功能至今没有定论。

哺乳动物的 vault 由 78 份主 vault 蛋白组成，这次找到的噬菌体版本由 96 份单一蛋白组成。团队把蛋白的一部分做重复，工程化出更大的壳体。论文已投给 bioRxiv，预印本链接尚未生效。

选择原核版本的理由是研究速度：细菌生长快，适合追问 vault 从哪来、基本结构如何、里面装了什么。团队把蛋白部分重复后得到更大的壳体，指向的用途之一是作为递送酶的纳米胶囊。这类结构与人类免疫里 cGAS–STING、gasdermin 的细菌同源物研究路径相似。

结构细节也被公开：壳体顶部由 48 条链从边缘向中心缠绕，三分之一越过第一层直抵顶点，所以盖顶像阶梯状的穹顶。

Claude 承担的是检索蛋白数据库、设计 DNA 构建、优化分离方法、处理显微图像。按团队说法，常规需要三天的 vault 纯化压缩到约 90 分钟，首个结构模型在 34 小时后完成，而他们估计过去要数周。

这项工作的价值在于把“读文献、试条件、处理数据”几段串起来，而不是替代科学判断：vault 的功能仍未确定，这既是研究目标也是当前缺口。90 分钟与 34 小时是团队自述的对照估计，没有同题平行实验；参与评论的 Leonard Rome 是该项目聘请的顾问。

## 五、同一天两种“开源”：Kimi 放出 5.6TB 权重，混元说“计划开源”

月之暗面按 10 月 24 日的承诺，在 Hugging Face 开放了 2.8 万亿参数的 Kimi K3.1 Pro 权重，并登上 Agent Arena 的开源模型榜首。权重约 5.6TB，消费级硬件无法本地部署；Databricks 同日宣布 Day 0 上线，其员工称团队已用于内部编码。对多数团队来说，5.6TB 把部署门槛从算法问题变成了存储与带宽问题，托管服务因此比自建更现实。

腾讯混元发布 Hy4：770B 总参数、MoE 架构、100 万 token 上下文，第一次加入视觉理解与 Computer Use，主打金融、办公、前端游戏与科研。团队同时承认与顶尖闭源模型仍有明显差距，权重“计划开源”，正式版权重尚未放出。

腾讯给了一组自测：579 个真实金融任务、213 位从业者参与评分，Hy4 得 3.04（四分制），DeepSeek-V4.1-Flash 2.97，Kimi K3.1 Pro 与 GLM-5.3 均为 2.68；搜索类幻觉率从预览版的 15.76% 降到 5.45%。价格维持预览版水平：输入每百万 token 6 元、输出 18 元。

同一批材料里，十二项主表 Hy4 多数排在第二到第四，没有总榜第一。开源阵营内它与 Kimi 大致打平：代码、三维建模、检索和科研偏 Hy4，终端自动化偏 Kimi。科研内部基准 TenureTrail 上它约 53.6 分，Claude 约 59；一个官方案例是用 84 张二维切片、约 699 万个细胞，在离线环境花 1.5 小时完成小鼠胚胎三维重建。

对部署方，这两个发布回答的是不同问题：一个现在就能下载并接进自有集群，一个现在只能通过 API 和腾讯产品使用。自测分数与榜单都来自厂商，跨模型比较要连同评测条件一起看；Kimi 的首位排名同样是平台榜单，不是独立复现。

## 六、Images 2.6 把生成图接进设计流水线

OpenAI 11 月 4 日发布 Images 2.6，ChatGPT 与 Codex 所有订阅档位可用，同时开放 API。主要变化有三件：可导出 SVG 矢量图、可生成 GIF、出图速度比上一版快约 50%，改图时只改指定区域。

API 里有两个版本：Flare 偏速度，低画质下最快约 6 秒一张；Sunburst 偏画质，中高画质下细节更多，连续多轮修改时主体更稳定。此外还有图片标注与复杂度参数，后者控制模型动笔前安排画面的工夫。

SVG 输出是这次真正改变工作流的一项：图标、Logo、插画不必再由设计师照着位图重画，可以直接进入设计软件和前端代码。GIF 走的是精灵图路线，先把多帧画在一张图上再按顺序播放；合作方 OpenArt 公开的示例是先让模型按 3 列 2 行画出 6 帧连续动作，再抽成循环动画。

OpenAI 给出的用量背景是：全球用户每周在 ChatGPT、Codex 和 API 上生成 40 亿张图，平均每天超过 5 亿张。设计工具 Figma Weave、图片编辑应用 Picsart 已经提前接入。

公告把 SVG 导出写在开发者功能里，没有说明 ChatGPT 内是否能直接导出；速度与画质的对比均来自 OpenAI，尚无第三方测试。定价与 2.5 相同：生成每百万 token 30 美元，输入参考图 8 美元、输入文字 5 美元。

## 七、DeepSeek 想让智能体自己管自己

DeepSeek 的技术文档提出 Super-agent 架构，出发点是人的注意力：一个人同时只能跟踪 3 到 5 个智能体会话，再多就会成为瓶颈。方案把调度拆成三层——Router 分发任务，Worker 并行执行，Watchdog 检查谁卡住或跑偏，任务是盯 GitHub 讨论、查 bug、开 PR。

模拟测试里，任务耗时的 95 分位从 29.5 分钟降到 15.7 分钟，接近腰斩，代价是 token 消耗明显上升。

这组数字值得注意的地方是评测口径：它量的是完成时间，没有量代码质量，也没有量返工率。编排层的收益和成本因此没有配平——省下的是等待，付出的是推理预算。文档也没有给出人工复核的成本，验收这一步仍留在人这一侧。

目前公开的是开源 Harness 原型与一份架构提案，Super-agent 本身还不是产品；数字来自技术文档的转述，未见独立复现。社区同期在讨论多智能体协作时“谁来验收”，这恰好是这类架构没有回答的部分。

## 八、一天合并三万次变更：审查从“读代码”变成“看证据”

负责 Claude Code 开发者体验的 Addy Osmani 在一场对谈里给出两组数字：Anthropic 今年 5 月每天合并约 2,500 次代码变更，9 月已超过 3 万次。近期网页版重做把性能提到约三倍，短时间内合并了约 3,000 个 PR，参与者包括产品设计师等非工程岗位。

流程分三步：先让 Claude 以真实用户的方式把功能跑一遍，端到端测试、浏览器检查、各类工具与规范检查都做，发现问题由 hook 自动触发修复；再把团队的品味写进 CLAUDE.md、AGENTS.md 一类文件，供 AI 审阅时参考；最后人才介入，看的不是逐行代码，而是 AI 交上来的录屏、截图和测试结果。

支持这个判断的不止 Anthropic。CircleCI 今年分析 2,800 万次自动化流水线，代码产出量增长 59%，但每 10 次往生产环境合并有 3 次失败；Sonar 的调查里，76% 用 AI 生成代码的开发者说产出速度快到来不及验证。

Addy 把这种模式分成“亮灯工厂”和“熄灯工厂”：前者 AI 干活、人仍在环内用品味把关，后者人退到上游只定方向。Sonar 的调查显示目前只有 5% 的公司在用软件工厂，预计会升到 34%。他自己的判断是，到 2027 年底多数团队仍是亮灯工厂，只带一些熄灯的角落。

他在对谈里也给出了可以照抄的验证分层：规则固定的自动扫描查 SQL 注入一类已知问题，AI 审查查规则扫不出来的逻辑与意图问题，供应链检查看依赖包里有没有已知漏洞或恶意代码。每一层负责一类失败，而不是互相替代。

这是一份内部经验的转述，不是受控实验；Sonar 本身销售代码检查工具，对“验证不足”的判断有立场。可以带走的结论有限但具体：省掉逐行阅读的前提，是先把验证做成可交付的证据，而这一步大多数团队还没搭好。

## 十、Google 把“主观标准”做成了人机来回谈判的流程

Google Research 11 月 4 日公开 Agile Deliberation，处理的问题是主观类别的图像分类器怎么训：训练流程通常假设标注者心里有一份稳定、完整的定义，但“健康食品”“不误导的抽奖广告”这类类别的边界会随文化、个人立场和运营政策移动。

框架把定义拆成两个阶段。概念划界阶段，系统引导用户把大概念拆成子类别，并显式写出排除项，例如把“健康食品”拆成沙拉、谷物碗、瘦蛋白，同时排除加工食品与未烹调的原料。概念迭代阶段，视觉语言模型主动挑出语义上处于边界的图片交给用户判断，比如一杯果昔算不算健康饮食，再把反馈接进自动的提示词优化循环。

与主动学习不同的是，这里挑选样本的目标不是降低模型的不确定性，而是逼出用户自己没说清的假设。团队把代码与算法在 GitHub 开源。

评估方式值得一提：主观类别没有静态的客观真值，离线标注集无法衡量“人的定义在过程中如何变化”，所以他们做了 18 场、每场 1.5 小时的真人实验，按随机顺序让参与者分别使用该框架与三种基线：一次成型的零样本分类器、由 AI 自上而下拆解概念的“建模协作者”、以及在表格里手工找异常的“人工审议”。

结论是定性偏多：参与者的标注一致性更高，分类器在多数基线上表现更好，差距在最难的主观图片上最明显；专家用户还把它当作诊断工具，用来发现自己初始定义里的盲区。公开文章没有给出具体分数，因此“更好”目前只有方向，没有幅度。

对做内容审核或视觉筛选的团队，这个流程真正的价值在于把模糊的运营标准写成可复核的规则：反馈落在具体边界图片上，而不是靠反复改写提示词猜，团队称这降低了用户的疲劳与焦虑。规则一旦显式写出，就能交接、能审计，这通常是主观分类器进入生产环境最先卡住的地方。

## 高价值单点

- **uni-robot-agent**：清华与伯克利开源的五层机器人 agent 框架，让不专门为机器人训练的开源模型零样本操作机械臂。同一个 Qwen3.8-Flash-Next 在 RoboDojo 上从 1.90 分升到 31.39 分；GPT-6 Astra 用同一框架为 51.90 分，真机双臂任务 80.50 分对 53.50 分。作者也说明每任务只跑 6 局时分数波动约 8 分。
- **Google 把 AI 与搜索绑在一起**：即将推出的 K-12 设置里，Search、Gemini 等默认关闭，由管理员开启；但没有只开无 AI 版 Search 的选项，拒绝 AI 的学校会同时失去 Search。

- **SFA 注意力**：保留细粒度局部交互，按逐级变粗的尺度汇总远端区域，前向与反向复杂度均为 O(N log N)。262,144 token 下 Triton 实现相对 FlashAttention 前向提速 357.3 倍、反向 265.6 倍，属注意力算子指标。
- **AppMem**：无需训练，按应用组织结构化记忆并追踪跨应用中断的意图。论文报告 GPT-5.5 的路径加权成功率从 15.7% 升到 66.9%。
