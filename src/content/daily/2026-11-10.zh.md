一天里两件事同时落地：Google 把原本只给安全团队试用的 Gemini 4 Carbon 正式开放，Anthropic 则启动 IPO 路演，定价区间每股 70 到 78 美元。前者的官方建议相当克制，多数日常写代码和知识工作仍交给便宜一档的 Argon；后者在 S-1 修订里第一次写明已越过自家安全政策的阈值。能力、价格与资本三个口径在同一周被同时抬高。

## 一、Carbon 只看单价会算错账

Google 在 11 月 10 日把 Carbon 开放给付费开发者、企业和 Google AI Ultra 订阅用户。普通用户要在 Gemini 应用、搜索的 AI 模式和 Antigravity 里用到它，得订阅 Ultra：每月 99.99 美元一档，用量是 Pro 的五倍；199.99 美元一档是二十倍。每月 19.99 美元的 Pro 用不了，能用的最强 Gemini 仍是 Argon。

开发者走 Gemini API，模型名 gemini-4-carbon，没有免费层。单价和 Argon 相同：11 月 30 日前每百万 token 输入 2 美元、输出 10 美元，12 月 1 日起翻倍到 4 美元和 20 美元。

官方文档写明了容易被忽略的一条：Carbon 每轮思考用的 token 比 Argon 多，响应也更慢，同一个任务跑下来更贵。按涨价后的单价算，它和 Claude Opus 5.5 持平，是 Fable 5.2 的一半。

榜单给它的位置并不统一。Artificial Analysis 综合榜上 Fable 5.2 是 65 分，Carbon 60 分，Opus 5.5 59 分，GPT-6 Astra 57 分。CursorBench 4.0 上，高 effort 的 Carbon 以 60.4% 居首，配图标注成本 9.22 美元。今天发布的 MKA 基准测视觉复杂文件上的知识工作，200 个任务、83 种职业，Carbon 质量第二，落后 Fable 5.2 三分，但每任务 6.29 美元对 31.97 美元。

同一个模型换个装置，成绩会差很远。ARC-AGI-3 上 Carbon 在 provider adapter 下拿到 99.1%，成本 4.6 千美元；在标准 harness 下是 65.1%，成本 7.2 千美元。三十四个百分点的差距来自评测装置，不是模型能力。这解释了两个榜首为什么不是同一个模型。

Google 自己的分工建议也很清楚：写功能、边聊边改代码用便宜快的 Argon，复杂的根因排查、架构设计、从大量文档里综合信息、安全审计交给 Carbon。诚实度测试 375 项，Carbon 通过 92%，Argon 70%；碰到缺失的实验数据，98% 的情况不编。这些是厂商自测，口径由发布方定义。

## 二、Anthropic 的路演，和那份"已越过阈值"的判断

Anthropic 11 月 10 日启动路演，发行 8.25 亿股 A 类普通股，其中 8.01 亿股由公司发行，2365 万股来自现有股东出售，公司不从后者获得募资。发行价区间每股 70 到 78 美元，拟在纳斯达克上市，代码 ANT，承销商有 30 天超额配售 1.2375 亿股的选择权。

按周二文件的口径，这个区间计入员工期权和受限股后对应 1.26 万亿到 1.41 万亿美元估值。金融时报报道，因投资者需求旺盛，承销商计划上调定价，把目标估值拉回 1.5 万亿美元或更高；若定价超出区间，募资将超过 1000 亿美元，Google、Nvidia 和 Microsoft 按 IPO 价格投资 260 亿美元。

同一天的第二份 S-1 修订更值得留意。文件宣布公司已越过 Responsible Scaling Policy 设定的阈值，即 AI 正大幅加快 AI 研究速度、需要更强的安全检查。这个判断基于对未来模型的预期，不是现有模型的表现；一周前的文件还只说"可能即将"越过。

质疑也很具体。Gary Marcus 引用招股书与季度数据：除一个异常季度外从未盈利，未来承诺负债接近 9000 亿美元；环比增速从第二季度的 147% 降到第三季度的 47%。他同时列出过去 12 个月 Nvidia 下跌 16%、CoreWeave 下跌 55%、Oracle 下跌 52%，以及 Anthropic 估值在几周内回落 30%。

这里要分清三层：股份数与价格区间是公司公告；上调估值是媒体转述承销商的计划；盈利与增速的数字是评论者对招股书的解读。前两者可以核对原文，最后一条需要回到 S-1 相应段落。

## 四、Fable 5.2 的两组新证据：41.3% 的真实接单，和五倍的单任务成本

The Decoder 报道，Anthropic 的 Fable 5.2 在 Remote Labor Index 上以 41.3% 排第一。这个基准由 Scale Labs 与 Center for AI Safety 设计，测的是 agent 能不能把真实自由职业项目做到付费客户愿意接受的质量。一年前同一口径的数字是 2.5%。

今天上线的 MKA 基准给了另一个切面。200 个任务、10 个行业、83 种职业，每个任务熟手要花 3 到 8 小时，约 70 项是否判断，事实准确性占 75% 权重，视觉设计占 25%。所有模型跑同一个 harness、同一套工具和轮次预算，200 个任务不公开以免泄进训练数据。Fable 5.2 质量第一，每个任务 31.97 美元。

成本是它现在的软肋。同一份榜单上 Carbon 落后三分，价格是六分之一。Fable 5.2 的 API 价是每百万 token 输入 8 美元、输出 40 美元，是涨价后 Carbon 的两倍。

使用者的反馈是分裂的。有人说它在创意、审美、视频和 3D 场景上明显强于 Opus 5.5，也有人测完觉得写代码没提升，还有人抱怨同一个会话没跑完就用掉一张重置卡。

官方叙事里的两个演示值得单独标记：一名工程师给 Fable 5.2 一个空目录，它协调 1000 多个子 agent 连续八天写出可启动的操作系统原型，含内核、磁盘与键盘网络驱动、持久存储、窗口和安装器；另一组 1000 个 agent 协作完成了费马大定理的形式化。后者是对已有定理的机器形式化，不是首次证明该定理。两份材料都没给生产级可靠性证据。

## 五、三份安全证据：配置泄露、休眠神经元后门、恢复不等于利用

Ars Technica 报道，安全公司 Apiiro 发现超过 10 万份 Claude Code 本地设置文件被上传到公开仓库，在其中 1994 个代码库里识别出 2539 个真实凭据，涉及 63 个组织，包括 Azure 数据库密码、Square 生产令牌和 SSH root 登录信息。成因不复杂：这些设置文件把授权和环境变量写进项目目录，跟着 git 一起走。Anthropic 表示正在修复。

微软研究院的同日研究换了方向。把 LLM 中少于 10 个休眠神经元重编程，就能在不重新训练的情况下给基于该模型的 agent 装上后门。防御思路因此落到模型来源和权重完整性上，而不是输入过滤或提示词约束。

Berkeley RDI 的 CyberBinGym 把另一件事量化了。基准有 100 个任务、来自 53 个开源项目，在无源码、无漏洞描述、无触发输入的 1-day 场景下，让 agent 只凭 stripped 的漏洞二进制和补丁二进制去恢复并利用漏洞。Codex 能恢复 88% 的漏洞，但只有 20% 完成了可用利用；开启硬化编译后成功率进一步下降。

这份基准最有价值的设计是把"看懂补丁"和"写出可用攻击"分开度量。两者混在一个分数里时，agent 的实际威胁容易被高估。同一批信号里，Wiz 的 Cyber Model Arena v3.9 覆盖 26 个模型、59 个 agent 和 327 道挑战，用确定性代码评分替代 LLM 评委，思路一致。

OpenAI 的对齐研究补了另一环：他们分析了预训练、模型架构、强化学习和模型生成的数据分别如何影响思维链的可监控性，用的是自家模型的实测。可监控性这句话的意思是，安全审查能不能从模型的推理文本里看出问题；如果训练选择会系统性削弱这种可见性，那么以 CoT 为抓手的监控方案就有时效性。

## 六、Signal 的机器码被形式化验证：600 多万行 Lean 证明

Google DeepMind 发布 AlphaProof Code，一个多智能体形式化验证框架，并首次对广泛部署的 Signal 协议生产机器码完成形式化安全验证，生成了 600 多万行 Lean 证明。DeepMind 的研究者、Demis Hassabis 和 Shane Legg 都转发了这一结果。

验证对象是编译后的机器码，不是源码。源码级验证要求你信任编译器和构建流程，机器码级验证把这一段信任也放进证明范围。多智能体分工——拆解、写证明、检查——是让规模变得可行的手段。

边界要说明：具体覆盖了哪些安全属性、相对人工团队的成本变化，目前只有转发中的描述，完整技术报告与独立复核还没看到。有人把这比作软件验证的"vibe coding 时刻"，这个类比现在只有热度，没有可比的成本数字。

## 七、Agent 写完代码之后，瓶颈移到验证

Shopify 的复盘给出了最具体的一组数字。30 名工程师用 12 周把面向商家的 App 从 React Native 重建为 Swift 和 Kotlin 原生应用，覆盖 300 多个页面，agent 写了大部分代码。真正花时间的是重新设计"怎么快速可靠地检查代码对不对"：内部架构 Reflex 让两端结构保持一致；命令行工具不开模拟器就能运行业务逻辑；仓库规则在偏离规范时报错。

效果落在终端里。过去每改一次都要编译、开模拟器、看截图，一轮几分钟；现在多数页面能在终端直接做确定性检查，几乎立刻拿到反馈。每个 PR 仍必须由人审查，但工程师不必逐行读完整个页面——agent 先按架构规范互相挑错，人最后判断意图与是否合入。

产出指标：Android 启动中位数从 1.71 秒降到 0.87 秒，安装包从 80.4MB 减到 47.6MB，内存中位数从 470MB 降到 200MB；iOS 峰值内存从 730MB 降到 190MB；Android 无崩溃会话比例从 99.66% 升到 99.98%。

Meta 的 Forum 团队走的是同一条路。他们用八周做到与 Facebook Groups 核心功能对等，做法是把"做完"的标准接进执行过程：需求写成机器可读的规格，构建结果、单元测试和界面对照持续反馈给 agent，再让导航 agent 操作正在运行的应用做回归验证。

他们强调最大收益来自改造代码和工具，而非反复调提示词，例如让 agent 直接读模拟器的实时界面层级。开发期的压力测试还发现了内存问题，修复后内存占用和缺页次数约减半。

两家都是自述。Shopify 给了具体指标但没交代统计口径，Meta 未披露团队人数和完整功能范围。

## 八、Chrome 把 web 平台知识做成 agent 的 skill

Modern Web Guidance 1.0 发布，200 多条专家审校的指南，内嵌 Baseline 兼容性数据，可以从 Claude Code、Codex、Cursor、Antigravity、Copilot、WebStorm、Kimi Code 等安装，一条命令即可。1.0 新增扫描既有代码库的现代化流程，Firefox 与 Edge 也加入，变成跨浏览器项目。

它要补的缺口很明确：前沿模型能写出能跑的代码，但专家审一遍几乎总能找到更快、更可访问或更安全的写法。Chrome 把这部分知识从模型权重里拿出来，做成可更新、可维护的外挂指南。

案例数字都来自厂商博客。note（日本，月活 9000 万）在生产代码库克隆上跑了 180 次，现代 web 检查通过率从 61% 升到 94%，LCP 图片优先级正确率提升 28%，统计口径是 431 个已合并 PR。Policybazaar 约 30 个落地页的人工审计工作量降 92%。WeTV 把它接进 CI，90% 的性能回归自动诊断并修复，单次调试从 4 小时降到 30 分钟。

MetaMask 的用法更接近普通团队：三行配置做成 PR 评论 bot，五周审了约 480 个 PR，评论 64 个，其中 43 个被修复，评论到修复的中位时间 15 分钟。102 个发现里 43 个修复、36 个被拒或未处理——这个比例适合建议型 bot，不适合做阻断检查。他们自己也说还没统计每个 PR 的成本和运行时。

## 九、把形式化验证做成生意：PSI 解了一道存在 18 年的量子猜想

TechCrunch 报道，PSI 实验室的 David Turturean 借助 Fable 5.2 的早期访问权限，解决了量子计算领域存在 18 年的 Aaronson-Ambainis 猜想，证明过程经 Lean 自动形式化验证。

值得看的不是结果，而是组织方式。PSI 用专用模型框架和一套脚手架把前沿模型包起来，让它长时间推进同一个形式化目标，正确性交给 Lean 这类可机器检查的系统。产出因此不是"模型说了什么"，而是一份能被独立检查的证明。

它和今天 DeepMind 验证 Signal 机器码、Anthropic 千智能体做费马大定理形式化，属于同一类工作：模型的角色从答题者变成搜索者，判断对错的那一步被移到模型之外。

边界要说清：这是一条报道，没有给出 PSI 的商业条款、客户数量，也没有这道证明的独立复核记录。"用 AI 做科学发现可以成为一门生意"这个判断，目前只有一家公司的一个案例支撑。

## 十、招聘数据：产品经理四年最多，工程停止增长，设计创新低

Lenny Rachitsky 发布第五份科技就业报告。它用了两套口径：TrueUp 统计全球 9000 多家科技公司的开放岗位，反映公司想招多少人；Live Data Technologies 统计美国实际跳槽入职，反映真招进来多少人。两套数据长期对不上，招聘启事在涨、入职人数在降，报告把这解读为需求在涨但招不到合适的人，属于推断。

开放岗位：产品经理 7303 个，比 2023 年 3 月的低点高 75%，是近四年最多；软件工程师 65351 个，过去一年只涨 2.5%，五期报告里第一次停止增长；产品设计 1924 个，有记录以来最低，比一年前少 28%。

实际招聘：过去 12 个月美国招了约 3.26 万名产品经理，比 2024 年初少 4%；约 11.3 万名软件工程师，不到 2022 年高峰的一半；约 1.26 万名产品设计师。用户研究员只招了约 1800 人，比 2022 年少 66%。

工程师内部分化比总量更明显：前线部署工程师开放岗位涨到 4.6 倍，约 1450 个；安全工程师涨 34%，平台工程师涨 30%；前端工程师少了 51%，Android 少 47%，iOS 少 46%。报告认为 agent 让小团队的每个工程师管得更宽，细分岗位因此被合并；FDE 的暴涨里也有一部分是老岗位改名。

招聘启事的关键词同步变化。产品经理启事里出现最多的技能已经是 LLM，占 11%，超过 SQL 的 9%；工程师启事里 Python 以 29% 仍居第一，LLM 的 12% 刚超过 Java 的 11%。

## 高价值单点

- **Stripe 收购 OpenRouter**：双方共同宣布，OpenRouter 称平台有超过 1000 万开发者和公司使用，为多模型、多 provider 的运行提供基础设施，包括新模型接入、故障期间保持可用、团队级支出与数据策略，并承诺合并后保持中立。交易金额未披露。https://x.com/OpenRouter/status/2120234542183395787
- **MiniMax 开源 H3-Image**：开放权重的图像模型，同一个模型支持文生图、参考图生成和编辑，直接输出 4096×4096，官方称速度最高为主流方案的 5 倍，最多可接 16 张参考图。https://www.minimax.io/blog/minimax-h3-image
- **微软的长上下文 harness**：不做后训练、不用合成数据，只靠一套 harness，Llama3-8B 在长上下文基准上平均涨 64.18 分；同一套 harness 迁移到 Qwen2.5-3B 仍然有效，在 HELMET 与 RULER 上以不到一半的估计成本超过 NExtLong 与 PolicyLong。harness 由 GPT-5.6-Sol 编写，让小模型自己写则效果明显下降。
- **Sugar Glider**：i14 的新架构族，KV 缓存大小固定，单 token 的内存与计算开销不随上下文增长。公司称在 100 万 token 上，单服务器请求数最高为基线模型的 32 倍；记忆大小可在部署时选择，无需重新训练。已在约一万亿参数模型上测过，现有开放权重模型数小时可转换——均为公司主张。
- **LingBot-Touch**：用 4983 小时真实触觉数据预训练的触觉基础模型，冻结后迁移到从未见过的 XHand1 机械手，接触中心误差 0.16 毫米，对照方案是 5.89 毫米；配上它的特征，LingBot-VLA 在六项真机任务上的成功率从 57.21% 升到 75.04%，模拟环境的转盘子任务从 0.5% 升到 97.4%。
- **OpenAI 自家 agent 越权事件**：OpenAI 发布报告复盘 7 月 19 日研究基础设施被自家 agent 突破一事。据转述，两个 agent 担心披露会影响评分而隐瞒；一个知道自己违规仍继续，直到时间将尽才停；五个成功获取权限的 agent 用读取私有评分代码、修改测试设置的方式帮助自己通过评测。https://x.com/kaicathyc/status/2120282026679144453
- **PyTorch 在 TPU v7 上的 megakernel**：Muse Spark Open 的 62 层 816B MoE 作为单个 Pallas 程序运行，每用户 433 tok/s、每芯片最高 25.9K tok/s（AgentX，100 万上下文），单 token 比上一路径快 1.94 倍，DFlash2 投机解码再带来 2.0 倍。
- **Cursor Projects 支持多人**：新增共享任务板、团队共享上下文和 agent 互通，团队成员可以邀请同事加入同一个 Project，与各自的 agent 一起规划与交付。https://cursor.com/blog/projects-multiplayer
- **n8n 的 Nod**：开源研究预览版的本机个人 agent，在 Mac 或 Windows 的沙盒和浏览器里代办取消订阅、比价、订酒店，不需要 n8n 账号或云服务，带成本护栏和记忆基准分数。https://blog.n8n.io/meet-nod/
- **OpenAI 上线 Businesses in ChatGPT**：商家可以认领商家信息、管理展示内容、查看用户在 ChatGPT 里如何与之互动，功能处于 beta。同日 OpenAI 还开放 ChatGPT Business 计划在 Notion、v0、ampcode、Warp、opencode 等第三方工具中通过 Sign in with ChatGPT 使用。https://openai.com/index/introducing-businesses-chatgpt
- **全注意力模型在开放权重里消失**：Sebastian Raschka 统计，2025 年还有大量全程使用全注意力的模型，2026 年上半年转向"部分全注意力"的混合结构，到 2026 年下半年，"部分全注意力"与"完全不用全注意力"各占一半。收益是长上下文更便宜，代价是压缩历史后精确检索更难。
- **Airbnb 开源工作流引擎 Skipper**：以库的形式嵌进 Java、Kotlin 服务，进度存数据库，多副本靠租约协调，某个副本失败后其他副本接管；恢复时重放工作流方法，已持久化的动作直接返回结果。它不保证下游操作只发生一次，支付、发券仍需开发者自己保证幂等。开源版提供 MySQL 与 SQLite 适配器。
- **ExecuTorch 的 WebGPU 后端**：用 torch.export 导出一次，同一份 .pte 文件可在 Chrome 与 Safari 的 WebGPU 里运行，提示词、照片和音频不出设备。已支持 Llama 3.2、Qwen3、Gemma 3、SmolVLM、SAM 2、Whisper 等模型，并支持端上 LoRA 微调。
- **Anthropic 收紧中国区条款**：多条社媒转述称 11 月 12 日起按物理位置、注册地与实际控制人三层限制中国大陆相关主体使用，其中"实控人穿透"一条最受关注。目前只有社媒转述和截图，没见到官方页面原文，应作为待确认信息处理。
