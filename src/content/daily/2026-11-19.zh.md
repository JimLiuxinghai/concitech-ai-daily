今天的两条主线互相咬合。Anthropic 在纳斯达克完成史上最大 IPO，83 美元发行价、111.50 美元开盘，募资 813 亿美元；同一天英伟达交出营收同比翻倍的季报，股价却收在 145.98 美元，创 52 周新低。资本对 AI 的定价和公司当期业绩开始分开走。另一条线是管制：美国把先进制程代工和海外算力通道同时收紧，中国公司的训练计划被迫改道。产品侧，Google 把实时世界模型和工具检索搬进 API，OpenAI 与 Cline 各自给出把 agent 当生产系统的样本。

## 一、Anthropic 上市：估值口径先打了一架

发行价 83 美元，高于此前 70 至 78 美元的预期区间。开盘几分钟股价到 111.50 美元，较发行价高 33%；随后回落，社媒汇总的首日收盘为 97.17 美元，较发行价高 17%。本次募资 813 亿美元，超过 SpaceX，成为有记录以来规模最大的 IPO。

市值出现了两个流传的数字。TechCrunch 按开盘价称市值超过 2 万亿美元，The Verge 按完全稀释股本给出约 1.5 万亿美元。两者不是同一个尺子：前者是盘中价格乘股本，后者对应发行价口径。引用时最好把口径一起写出来。

股东结构同样是这轮定价的一部分。Amazon 持 14.7%、约 1590 亿美元，Google 持 13.7%、约 1490 亿美元；Nvidia、AMD、Microsoft、Broadcom、Micron、TSMC 还以 83 美元参与了 260 亿美元私募。招股材料另一面是承诺：长期算力与基础设施采购 9009 亿美元，其中未来 12 个月到期 707 亿美元；截至 10 月底年化营收跑速 810 亿美元、隐含毛利率 85%，算力与基础设施吃掉近六成营收。FT 的测算是，要在约 1 万亿美元算力承诺上拿到 20% 回报，需要约 6020 亿美元年收入。

控制权没有随股权稀释。七位联合创始人平分股权，按 83 美元发行价计算每人账面约 200 亿美元；七人合计 12.8% 的经济持股，却握有 50.1% 的投票权。这意味着公开市场买到的是现金流，不是决策权。对一家把"安全"写进公司章程的公司，这套结构既解释了它为什么敢在 IPO 当天重申放慢部署，也解释了外部股东为什么很难改变它。

同一天，AI 安全圈出现《MisAnthropic Statement》，签名者横跨安全派、开源支持者与 e/acc，指责公司一边讲安全一边推进自己警告过的技术，并借监管巩固位置。Dario Amodei 的上市声明则强调不向商业或政治压力低头，会放慢训练与部署节奏；他以自己的生物学背景和 Claude 在科研中的应用为例讲使命，同时承认滥用、经济冲击与失控三类风险，并提倡行业"向顶部竞赛"。联署表达的是立场分歧，不构成事实指控；财务细项来自长帖转述，未见原始招股书，需要保留这层不确定性。

## 二、英伟达：财报翻倍，股价在同一个季度见底

第三季度营收 1158.44 亿美元，同比翻倍；净利 653 亿美元；数据中心收入 1076 亿美元，占九成以上；Vera Rubin 平台已开始出货，贡献近 200 亿美元。这是硬件侧少见的强劲数字。

股价走的是另一条线。受芯片股整体抛售、前 CEO 黄仁勋辞职与公司治理调查影响，股价一度报约 150 美元，较 10 月 6 日历史高点跌近 40%，周四收于 145.98 美元，创 52 周新低。公司目前由临时 CEO 主持，董事会仍在寻找正式继任者。

治理层面的动作也在加密。1 万多名员工、约占员工总数 24%，联署要求请回黄仁勋；Bezos 公开表示，复杂公司空降职业经理人的成功率极低。黄仁勋本人则公开说"很愿意回来当 CEO"。董事会新设常设的国家安全与全球贸易合规委员会，由独立董事 Suzanne Nora Johnson 任主席，至少每季度开会，并外聘法律与贸易独立专家，合规团队向委员会和临时 CEO 双线汇报。

边界在原因上。辞职的具体理由官方没有说明，社媒把"国家安全"和辞职连起来的说法只是推测，不能当结论；员工联署与 Bezos 表态都来自转发，未获公司确认。

收入结构也更集中：数据中心占九成以上，Vera Rubin 已贡献近 200 亿美元，说明新平台开始接棒。基本面和股价的分叉，本质上是对"这种集中在管制与治理变动下还能持续多久"的定价分歧，而不是对上一季度数字的分歧。

## 三、管制同时收紧代工与海外算力

美国 BIS 11 月 16 日发布的新规在 11 月 19 日生效：采用 16/14nm 及以下工艺，或非平面晶体管架构制造的特定先进逻辑芯片，代工厂与封测厂需先推定其属于 3A090.a 类；此前用晶体管数量证明"不受控"的豁免途径被取消；对客户最终母公司、实际控制关系和交易用途的审查也同步加强。

另一条临时规则针对算力通道：海外数据中心要向中国公司提供大量算力，需先取得许可证，已在运营的给 90 天缓冲；新加坡、马来西亚、泰国、印尼、巴西五国进口先进 AI 芯片同样需要许可。

后果已经落到具体合同上。Moonshot AI 取消了与印尼云服务商 1.5 亿美元的合同，原计划租用 Nvidia Blackwell Ultra B300 集群训练 Kimi K4，此前已预付约 50%，远高于行业常见的 15%；台积电和三星暂停向中国客户交付部分处理器，需申请许可；英伟达临时 CEO 公开表示不再向中国卖芯片。

影响面不止 AI 加速卡。非 AI 芯片的豁免被取消后，小米、Oppo、vivo 等厂商的手机处理器供应也开始受牵连。当天 A 股国产 GPU 集体大跌，天数智芯盘中一度跌超 25%，燧原科技跌停，而中芯国际、华虹宏力逆势上涨——市场把订单往本土代工推了一步。

需要拆开看的是传闻和规则。所谓三星做穿透式审查的说法，已被《上海证券报》向产业链多方核实后否认；新规的真实约束力取决于许可证发放尺度，个股跌幅和单家公司受影响程度都没有独立核实。

## 四、Gemini 4 Neon：价格位置比榜单名次更值得看

11 月 18 日发布的 Neon 补齐了 Gemini 家族的中间档：100 万 token 上下文、支持多智能体协同。Artificial Analysis 的综合智能指数 61 分排第三，编程智能体指数反超 Claude Opus 5.5 拿到第一，价格约为 GPT-6.2 Astra、Claude Fable 5.2 旗舰档的 37.5%。按 API 计价是每百万 token 输入 3 美元、输出 15 美元。

发布次日的实测开始分化。Jeremy Howard、Demis Hassabis 转发称它在多数任务上压过 Fable 5.2；Riley Brown 说它写代码和剪视频都好用，但写作有非常明显的"不是这个，而是那个"腔调，不建议拿来写作；向阳乔木认为开发效率上 Opus 5.5 仍然胜出。多人称它是"小模型"，官方没有公布参数规模。

订阅门槛本身也成了讨论点：4.99 美元的 Google AI Plus 用不了 Neon，要 19.99 美元的 Pro 才能选。这解释了为什么一个"便宜"的模型会在发布后引来大量换号、改区、找第三方客户端的操作。

Google 开发者关系团队给出的分工更清楚：Neon 做日常编码与 agent 的主力，Hydrogen 每百万 token 输入 1.5 美元、输出 7.5 美元，留给基础任务、闲聊和子智能体，Carbon 则用于可以慢一些的测试与长时程模拟。价格阶梯配上能力分层，实际是在卖"哪一档任务用哪个模型"的调度权。

证据边界：榜单分数来自第三方评测，参数规模是社区推断。如果"小模型"成立，说明蒸馏加后训练的效率收益已经能吃到旗舰档九成以下的价格，但目前没有官方规格可以确认。

价格压到旗舰的四成以下，改变的是默认选择。过去团队常按"最贵的最稳"来定主力模型，现在中间档在编程榜上领先，按 token 计的账单会比评测分数更早推动迁移。

## 五、Google 把世界模型与工具检索搬进 API

Genie 4 在 Gemini API 和 AI Studio 上线：可从文本或图像生成 720p、24fps 的世界，用 WASD、提示词和 48kHz 立体声实时操控，通过 WebRTC（浏览器加临时 token）或 WebSocket 串流。它是第一个跑在新 Live Interactions API 上的模型，官方的目标是把标准调用与实时长会话放进同一套接口。

把 720p 世界模型放进 API，难的不是生成，而是实时可控：键盘输入、提示词和音频要同时进，画面还要持续回传，所以它必须绑定低延迟的双向串流协议。这也解释了为什么 Google 要同时改 API 的会话模型。

同一天另一项是 Tool Retrieval 的预览。agent 按需加载工具参数 schema，而不是每次请求都发送完整工具库，以此减少输入 token，并在工具数量扩大时保持选择准确。对工具库上百个的团队，这比换模型更直接。

这里有个明确的取舍：工具越多，把所有 schema 塞进上下文越贵，模型在长列表里也更容易选错；按需检索把这两件事一起处理，代价是多一次检索调用和相应的延迟。它解决的是规模问题，不是能力问题。

Mac 版 Gemini 应用则上线了 computer use：跨文件夹、应用和网页代任务，官方演示里把草图变成 Blender 中绑定的 3D 模型，屏幕和光标控制权仍归用户。三件事指向同一个方向——把实时环境、工具选择和本机操作做成 API 能力，而不是产品里的单点功能。

这些都是厂商发布，Genie 4 的实际延迟、并发上限与计费方式还没有第三方测试，Tool Retrieval 在超大工具库下的准确率也只有官方说法。

## 六、OpenAI 用 Codex 自动修 ChatGPT 的性能回归

OpenAI 披露了 Performance Factory 的做法：用 Codex 智能体在云端自动排查并修复 ChatGPT 的性能回归。其中 Regression Workflow 在三个多月里跟踪了 1700 多次调查，定位超过 600 个根因，相当于每天约 17 次自动调查。

这类工作过去靠人盯仪表盘、翻 trace、手工复现。把调查和定位交给 agent 之后，人的位置从"找问题"退到"审修复"，工程收益主要来自调查吞吐，而不是单次修复有多聪明。

Regression Workflow 只是这套系统里的一条流程，Factory 的定位是把性能问题当成产线上的缺陷来处理：发现、归因、修复各有负责的环节，而不是留到发布前做一次人工体检。这个分工比具体数字更可复用。

边界要写清楚：这是 OpenAI 自述，没有给出误报率、漏报率、人工复核比例，也没有修复上线后的回滚率。原文正文被 Cloudflare 拦截，可核对的只有 RSS 摘要和早间精选的转述，1700 与 600 这两个数字暂时只能按公司说法引用。

## 七、Cline-Bench 把评测本身当成要防的对象

Cline 放出的 Cline-Bench 由 47 个来自真实用户请求的编码任务组成，每题跑三次，同时报 pass@1、pass@3 和 pass^3。它的重点不在题目数量，而在防作弊：在独立干净环境里评测、恢复受保护测试、缺失或跳过必需的测试算失败、用故意篡改过的解法反过来测评分器，任务说明和环境也经过人工修复以保住原始约束。

结果是一个很窄的分布。Gemini 4 Argon 51.1%、Opus 5.5 48.9%、Gemini 4 Carbon 48.9%、Sonnet 5.5 48.2%、GPT 6 Astra 与 DeepSeek V4.1 Flash 同为 44.7%、Kimi K3.1 Pro 43.3%、GLM 5.3 34.0%、Nemotron 3.5 Super VL 9.2%。换到稳定性看 pass^3，Opus 5.5 以 42.6% 最高，Carbon 只有 29.8%，DeepSeek 21.3%。

作者自己给了 95% 置信区间，宽度普遍超过 20 个百分点，第一名是 38.3% 到 63.8%，并明确说这组区间不支持把小差距读成能力差异。这个提醒比排名更有价值：47 道题能区分"能用"和"不能用"，还不足以区分头部模型之间的几个点。

榜单还记了时间与轮次，这比成功率更能解释成本。Gemini 4 Argon 平均解出时间 27.8 分钟、80.5 轮；Sonnet 5.5 只要 25.1 分钟、49.7 轮；GPT 6 Astra 14.2 分钟、59.9 轮；DeepSeek V4.1 Flash 14.4 分钟但用了 120.3 轮。同样四成多的成功率，背后是"想得久"和"来回试"两种完全不同的策略。

对采购方，这类榜单的正确用法是筛掉明显不能用的模型，再拿自己的仓库复测。拿它给头部模型排名，误差比差距大。

## 八、让 agent 改自己，也让它改别人的量化配方

Google 的 QUARD 把自改进的边界画得很窄：基座模型冻结，agent 只能编辑自己的 prompt、技能、工具规则和记忆，且一次编辑只有在收益大于它破坏的行为时才被接受。在 43 个托管 SDK 任务上达到 80.80% 准确率，比初始 harness 高 8.89 分（p=0.008），比 Meta-Harness 高 6.28 分，每任务少用 54.5% token；程序性记忆任务的更新正确率 90.1%，零记忆污染，而激进改写方法的污染量是三倍。

它判断"改坏了什么"的办法值得抄：每个任务先拆成若干自检项，每一轮按自检给轨迹打分，把已经稳定处理的规则钉住，再优先排序新出现的问题。测试时只跑一次冻结的 harness，不需要多轮搜索。

MIT 与 NVIDIA 的 QDA 把量化配方的搜索交给 agent：先用 KL 散度在几分钟内给候选打分，再对过关的候选做长生成以捕捉重复循环。W4A16、W4A8、W3A16 上分别比最强公开配方高 0.9、1.4、2.2 分，每次搜索消耗 64 GPU 小时；GLM-5.3-Flash 的 NVFP4 W4A4 恢复了 98.3% 的 FP8 精度，厂商 checkpoint 是 96.9%，且不需要新的推理 kernel。

两件事的共同点是把"调参"从人的经验变成可验证的搜索循环，用破坏检测或快速打分挡住退化。边界也一致：都是论文与作者转述，没有独立复现；QUARD 的收益在 43 个托管任务上成立，推不到开放式任务。

## 九、数据中心的电，正在变成下风州的健康账

MIT 团队在 Environmental Research Letters 发表研究，用逐小时电网建模追踪数据中心用电的排放传播：2023 年这部分额外空气污染在美国造成约 650 例过早死亡，其中 513 例来自 PM2.5、137 例来自烟雾，约占全国电力相关死亡的 5.3%。

关键是空间错配。研究用逐小时电网建模追踪排放传播，把发电结构、输电范围与数据中心负荷放在同一时间分辨率上，结论是污染和健康损害常落在远离设施的下风州，而电价、税收和就业收益留在机房所在地。这让"数据中心是本地经济增长"的说法需要附上一条注脚。

5.3% 这个比例也值得记住：它不是数据中心的排放总量占比，而是全国电力相关死亡中被归到数据中心增量用电的那部分。讨论 AI 的能源成本时，这是比"用了多少度电"更接近后果的指标。

这是基于电网模型的估算，不是逐例归因，结论对发电组合、电网结构和年份都敏感。

## 十、办公 agent 开始不要对话框了

微软在 Ignite 上发布的 Today 是个明确的信号。产品负责人 Nicolas Bustamante 说它不是 chat box 而是 feed：夜里 agent 在后台处理邮件、日历、Teams 和文档，早上打开就是草拟好的回复、发现的冲突、需要复核的文件；不用写 prompt，也没有配置项，人只负责发出、接受或标记完成。首批落在 Outlook 与 Copilot 里。

同一批信号还有几个。Devin Bot 正式上线，经过一千多名测试者打磨，能规划项目、调度多个 Devin 并持续验证改动，解除了"一次只跑一个任务"的限制；Perplexity 的 Multiagent 使用量一天翻倍，需求集中在可以并行拆分的任务，比如做演示、多源调研、财务分析和联系人清单。Aravind Srinivas 还提到，前一天上线的 Context API 按用户反馈补了 Decider 判断，先检查提示注入再抓取内容。

这条线的共同假设是：agent 的价值不在对话轮数，而在"你不在的时候它做完了一部分"。这解释了两件事——交互为什么从消息流转向卡片与清单，以及上下文、记忆和权限为什么比模型分数更快成为产品差异点。

接入面已经比模型更早决定谁会被用起来。Grok Bot 能连进 Obsidian 读写笔记，LangChain 的 Design Agent 直接住进 Slack 线程，Grok Bot 的另一条玩法是监听 Linear 里带 bug 标签的卡片，微软则把 Today 放进 Outlook 与 Copilot。agent 的入口正在变成用户已经在用的那个工具，而不是一个新的对话窗口。

边界：Today 只在 Outlook 与 Copilot 起步，Devin Bot 与 Multiagent 的增长数字都来自公司高管自述，没有第三方使用数据。

## 编辑结论

今天真正变化的是资金的定价方式和管制的执行方式，而不是某个模型又多了几分。Anthropic 用史上最大 IPO 换来了公开市场和几千亿美元的算力承诺，英伟达在最好的季报里跌到 52 周低点，说明市场已经在给"承诺"和"兑现"分开估值。技术侧的证据仍然偏慢：Cline-Bench 这类工作提醒我们，头部模型之间的几个点还分不清；而 Google、OpenAI 公布的自动化收益，都还是厂商自己的口径。
