## 一、黄仁勋承认婚外情，英伟达董事会启动独立调查

美国时间 11 月 8 日，英伟达董事会宣布成立由独立董事组成的委员会，并聘请外部律师协助，调查黄仁勋"成为外国情报行动目标"的相关报道。彭博公布了黄仁勋当天发给员工的邮件全文，标题是"致公司的一封信"，他在信中承认对妻子不忠，称"我的行为伤害了她和我们的孩子，我做的事没有任何借口"。

邮件后半段回应报道中的国家安全疑虑：董事会已启动独立调查，他支持并全力配合，同时表示自己"爱我们的国家"，致力于保护英伟达与美国国家安全。董事会声明称，没有理由相信国家安全或公司机密已受损，但调查将审查所有可获得的信息，并对黄仁勋及其领导团队表示信任。英伟达公共政策传播负责人 John Rizzo 表示，黄仁勋会在调查结果出来前继续担任 CEO。

这桩调查的源头是十天内《纽约时报》的连续报道：美国情报部门认定与黄仁勋关系密切的新加坡数据中心公司 Megaspeed 高管 Alice Huang 是中国情报人员，任务之一是打探信息并可能推动先进芯片进入中国。众议院三位共和党籍委员会主席已要求黄仁勋在 11 月 18 日前出席闭门简报。英伟达没有公开接班计划，本月晚些时候发布财报，这也是事件被放大讨论的原因。

证据边界需要讲清楚：情报结论来自《纽约时报》引述的匿名官员，没有公开证据；中国驻美大使馆称相关报道"毫无根据"，Alice Huang 本人未回应。《纽约时报》原文有付费墙，上述细节依据 Axios、彭博、Gizmodo、The Hill 等媒体的转述，董事会声明全文并未公开。

## 二、GPT-6.2 Sol 在灰度中出现，OpenAI 只说"明天"

11 月 8 日，多位用户称自己的请求被路由到一个自称 GPT-6.2 Sol 的模型。数字生命卡兹克用它跑了一个 Three.js 的 3D 交互页面，评价"审美强到爆炸"、防御性有明显改善；随后他用 20 个并发前端测试跑了 10 分钟，称 200 美元的 Pro 额度只掉了 1%。宝玉的表述更谨慎，只写"猜测是 GPT-6.2 要来了"。

同一天，OpenAI Developers 的账号发了一条只有"Tomorrow."和一段视频的推文。这让讨论迅速转向"下周一发布"，但截至这份日报截稿，OpenAI 没有发布任何模型公告，也没有公开 GPT-6.2 的可用渠道。所谓"发布会定在 11 月 9 日"是社区里 @daniel_mac8 的个人预测，不是官方信息。

对读者有用的部分不是预测发布日期，而是灰度这件事本身：模型在正式发布前先以未命名方式进入部分账号，已经是常规做法。所以单条使用体验只能算一个样本，额度消耗、代码审美、安全表现都需要在固定任务上重复才有比较意义。

## 三、DeepSeek Harness 报出 154 万日活，插件成了主战场

社交平台上流传的一组数字称，DeepSeek Harness 的日活在 36 天内增长 545%，达到 154 万，第三方插件约 35000 个，约 60% 的活跃用户至少构建或安装过一个插件。歸藏确认自己的设计插件被官方推荐，并提到"154 万日活"这个数字。Han Xiao 的使用感受是，Claude Code 和 Pi 从编程代理起步，而 dsh 从第一天就想做操作系统或超级应用。

这个定位在生态里能看出痕迹。Barret 李靖推荐了 Context 和 Agent-Team 两个插件，认为它们把 Agent 执行过程摊开给人看；社区里还有直接操作 iOS 模拟器和 Android 真机的插件、在对话侧边栏生成可玩游戏并导出单个离线 HTML 的 Game Studio，以及把微信读书书架接进界面的集成。宝玉转述官方说法："DeepSeek 希望 DeepSeek Harness 可以作为 Agent 时代的操作系统。"

需要保留的边界是，日活、插件数、安装比例都来自社交平台的转述，没有公司公告或财报可以核对。插件数量也不等于质量：35000 个插件里有多少仍在维护，没有任何数据支持。真正可观察的变化是，编程代理的竞争从模型能力转向了宿主环境能承载多少第三方扩展。

## 四、智能体"进化"的两面：新能力到手，旧能力流失

EvoAudit 的论文评估了四种智能体改进方法，结论不太乐观：16 个经过进化的智能体都在掌握新任务的同时丢掉了部分旧任务。多数可靠性增益还伴随部署成本上升，得分最高的版本也没有取得最大的平均提升。作者据此提出一套同时看能力保留、迁移效果和成本的评估流程。

另一条路线给出了正面数字。研究者提出的 Evolver 不改模型参数，而是把探索过程整理成结构化的"Gene"资产，任务开始时检索相关内容，再根据反馈修订。在 Terminal-Bench 2.1、SWE-bench Multilingual、SWE-rebench 和 GAIA 上，320 组配对实验的任务成功率从 83.13% 升到 87.50%，记录的 token 用量下降 24.24%；在 265 个两种方式都解出的任务上，token 仍下降 17.57%。

两条结果放在一起看，才有意义：智能体变强不一定靠换模型，也可以靠复用经验；但"变强"需要定义清楚是哪种强，否则新任务涨分的同时旧任务在退步，仪表盘上未必看得出来。Evolver 的实验设计是配对运行，这比单向对比更能说明 token 节省来自机制而不是任务变简单。

证据边界：EvoAudit 的结论覆盖其受测设置，不代表所有进化方法都会退化；Evolver 的数字来自论文作者自报的基准，尚无第三方复现。

## 五、不改权重也能变强：VISTA 让机器人自己改技能代码

清华大学与新加坡国立大学团队提出并开源 VISTA：模型权重保持固定，由一个 Meta-agent 主动做实验、修改技能代码和 Harness，再把改好的版本放回任务里验证。论文报告在 LIBERO-Pro 评估中，整体成功率从 17.5% 提升到 95.0%。

一个搬运案例可以说明机制：经过两轮修改后，该项任务从开发评估的 0/16 提升到 16/16。这里改的不是参数，而是"怎么做"的代码和调用方式，属于把调试过程交给模型自己完成。

这类结果容易被读成"机器人能力跃升"，其实不是。LIBERO-Pro 是特定仿真环境下的操作任务集，95% 只对应这些任务，不能外推到真实机器人。更有价值的观察是：固定权重加代码级自改，为不具备再训练条件的小团队提供了另一条提升路径，代价是评估与回滚要做得更细。

## 六、恶意 AGENTS.md 把编程代理变成攻击入口

据量子位转述 Forever Security 的发现，一条攻击链是这样的：下载目录里放一个恶意 AGENTS.md，编程代理读取后把它当成可信指令，进而修改全局配置、泄露凭证。关键问题在于代理默认会把外部文本当作指令源，而不是当作需要审查的数据。

这个攻击面随着代理接管终端而扩大。以前一份 README 只是说明文档，现在同样位置的文字可能直接触发文件写入和命令执行。给出的正文节选没有包含完整复现实验表，所以这里不引用具体的成功率数字，只记录机制。

同一天还有一条相关的基准结果：The Decoder 报道，在 Vals AI 的模拟企业网络攻击测试里，GPT-6 Sol Daybreak 完成了 80.8% 的目标，DeepSeek V4.1 Flash 达到 72.8%，后者成本约为前者的十分之一。这说明开放权重模型在攻防类任务上的差距在缩小，但模拟环境的表现不等于真实网络中的成功率。对使用方来说，可操作的结论只有一条：把代理的输入目录、凭证访问和配置写入权限分开管。

## 七、编程代理把人变成管理者，调试对象也变了

Addy Osmani 的文章《Your Coding Agents Made You a Manager》是当天传播最广的方法论内容。核心主张是：当你开始挑任务、交代背景、委派工作、验收结果，你已经在做管理，多开几个会话本身没有意义。他把自验证放在第一位：每个任务都应提供可执行的检查，测试、构建、类型检查、界面截图都算，Agent 应先执行、检查、修正失败，再带着证据交付。

他还有两条具体建议。任务说明应补充代码里看不到的信息：为什么做、业务约束、哪些事不要做、怎样算成功；重复出现的纠错可以沉淀为共享规则，但规则不是越多越好，模型升级后旧约束要清理。无人值守任务开始前，必须写清完成条件、验证方式、权限、运行上限、交付产物和审批人。

Barret 李靖从调试角度补了一半。他认为 Agent as a Service 成为常态后，调试 Agent 会变成高频操作，关注点会从 Function Profiling 扩展到 Decision Profiling：需要能在某个决策节点暂停、修改条件、Fork 出不同路径，再用回放和评估比较结果；系统层面则要从大量执行轨迹里找出反复出现的低效决策。

社区里还流传一个具体做法：Google 开源的 Elephant-Goldfish 插件把过程拆成两个角色，"大象"吃下全部历史并写出技术规格，"金鱼"零上下文只拿规格去压测，用信息差逼出规格里的漏洞。这条只有单一帖子描述，插件是否如描述般工作仍需自己验证。

## 编辑结论

这一天真正改变判断的不是某个模型，而是两件事同时发生：最大 AI 芯片公司的 CEO 进入正式调查程序，而代理生态的竞争已经转到宿主环境和插件上。前者会影响接下来几周的算力叙事和资本市场情绪，后者决定开发者实际留在哪个工具里。研究侧反复出现的主题则是同一个：让智能体积累经验，同时建立能发现它退步的评估。
