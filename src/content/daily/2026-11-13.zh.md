11 月 13 日的主线是英伟达：黄仁勋在任职 33 年后辞去 CEO、总裁和董事职务，CFO Colette Kress 出任临时 CEO。这条消息压过了当天几乎所有其他新闻，也把 AI 基建的融资风险推到台面上——美联储同一天发布的金融稳定报告显示，87% 的市场人士把 AI 列为首要金融风险，而春季这个比例是 50%。

另一条被情绪掩盖的线索来自 Google Research：Antigravity 的 /teamwork 多智能体系统公布了在数学、化学、系统软件上的具体产出，包括 Weil 猜想的完整 Lean 4 形式化。这两件事指向同一个问题——AI 能力正在进入需要长期验证的领域，而支撑它的资本结构正在被重新定价。

## 主题一：英伟达换帅，Kress 接手一家没有第二任 CEO 历史的公司

据 Latent Space 汇总的 SEC 文件，董事会于 11 月 11 日接受辞呈，此前已就《纽约时报》报道的绯闻事件展开独立调查。AI Valley 的记录显示，消息公布当天股价早盘一度跌超 13%，收盘跌约 4%，周五有所回升。Colette Kress 自 2013 年起负责英伟达财务，如今同时保留 CFO 职位。

市场关心的不只是人事。The Decoder 援引《华尔街日报》报道称，黄仁勋去职更多源于高风险业务而非私生活：英伟达曾向 AI 云厂商和数据中心开发商提供数十亿美元财务担保以换取营收分成，最大一笔是对 OpenAI 俄亥俄数据中心的 2500 亿美元担保，消息公布后股价跌 5%，Kress 已将该承诺减半。

这类担保把芯片收入变成了带信贷属性的交易。TechCrunch 采访的多位投资人判断，继任者风格更保守，短期难以延续黄仁勋每年数十亿美元、今年已参与 105 轮的投资节奏，AI 创业公司的融资会出现缺口。

谣言密度也值得记录。NVIDIA 副总裁 Bryan Catanzaro 明确表示，网上流传的"要求董事会恢复黄仁勋职务、并有他署名"的联名信是伪造的；同期 Elon Musk 公开表示正在签署另一份请愿。个人关系与身份指控目前没有可独立核验的证据，公司公告与监管文件正文也不在本次抓取范围内。

一线反馈比股价更能说明生态位置。Newcomer 在旧金山 Cerebral Valley AI Summit 现场的判断是：与会者多数认为 Nvidia 短期无碍，但生态承压，Databricks CEO 直接称这对整个生态是打击。以色列投资人的视角则更冷静——Nvidia 在当地有 6000 名员工和最大海外研发中心，决策放缓可能给推理软件与 AI 芯片的竞争者留出窗口，但如果不确定性同时压低整体支出，这个窗口面对的会是一个更小的市场。

## 主题二：Google 把多智能体用在证明和内核上，成果已过机器检查

Google Research 公布了 Antigravity /teamwork 的一批结果。最重的一项是与 CUHK、USC、CMU 合作，完整证明并形式化了 2013 年的 Courtade–Kumar 猜想：随机比特串经过噪声信道后，压缩到单个比特无法保留比"独裁函数"更多的信息。整个证明在 Lean 4 中形式化，规模达到 5000 万行代码。

与其配套的还有一批长期开放问题。LEAP 与 Argon 组合自主产出了 Weil 猜想的端到端机器检查形式化，约 180 万行 Lean、跨越 28,800 次子代理调用；此外还包括 Hilbert 第十问题在一般整数环上的首个形式化，以及 3D Navier–Stokes 有限时间爆破证明的复现。

工程侧的数字更接近日常。基于此前 25% 的移植进度，两周的 Argon 运行把 Zircon 微内核剩余 C++ 改写成约 80 万行安全 Rust，通过全部内核单元测试并在 arm64 硬件上启动；libgav1 从 C++ 改写为约 17 万行 Rust，达到 100% 位精确，最终比原 C++ 和手写汇编快 20–30%。九个 JAXBench 内核上 DuoDiscover 取得 4.09 倍几何平均加速，Borg 的调度工作流让部分硬件的 TPU 抢占下降 24%。

系统设计上有两点可复用的经验。一是用独立的"证伪器"（Lean 4 检查器、未修改的测试套件、硬件计数器）判断候选解是否成立，而不是依赖模型自我评估；二是按构造切分上下文，每个子代理只拿到当前步骤需要的文件和工具，审计者在不带原始推理的干净上下文里复核。

人类专家的位置没有被抹掉，而是被前移了。CUHK 团队先提出把猜想归约为 14 个变量的优化问题，并给出关键解析下界，Gemini 4 Argon 随后切分参数空间、补齐大部分新解析界与区间算术证书，最后才由人确认形式化定理陈述与原问题一致。另一条产线用 29 个 Agent 在 11.5 小时内把 13 张公开表做成 50 题因果推断基准，评审与审计 Agent 负责否决走捷径和幻觉脚本。

长程自治还做了一次可比的实验：从基础 AlphaZero 实现出发，爬山团队在 Argon 上从零训练 9x9 围棋引擎，人力只负责分配芯片和设定评测方式，八天内约涨 2600 Elo、达到 1885，落在 KataGo 每步 16 次与 32 次访问之间。冠军的晋级只靠锁定记录上的统计检验，而不是人来挑。

面向外部的时间表也给了。当前 Gemini 4 系列可搭配 /teamwork 与 /boost 在 Antigravity 使用，Deep Review 已开放给论文作者；Google 另开放 10,000 名学术研究者六个月的免费高额度申请，正式证明模式与更多专用工作流会在接下来几周进入 Antigravity。

证据边界：这些数字全部来自 Google 自己的博客，属厂商自述，多数尚无独立复现。化学部分的 95% top-1、100% top-3 是特定分子基准上的结果，不等于通用的结构解析能力。

## 主题三：智能体开始有钱包，也开始有身份协议

OpenAI 推出 ChatGPT Wallet，dot 可以在用户批准下代其完成购买。关键机制是智能体不接触真实卡号，每笔购买都要通过一次安全检查，原有信用卡权益保留。即日起在美国面向 Pro 订阅用户的 dot 开放。

同一天 Sierra 发布 Personal Agent Protocol（Poppy）v1.0，处理的是另一个方向的问题：个人智能体如何向企业证明"我是谁、我被允许做什么"。企业在自己域名下发布 `/.well-known/poppy.json`，声明可用入口（网站、OpenAPI、MCP 或企业自有 Agent），用户在企业自己的页面通过 OAuth 授权，之后同一会话可在网页、API 和对话间延续。

落地进度比协议本身更有信息量。Shopify 平台上的每家店铺已自动发布 Poppy 文件，商户无需开发；Meta 的个人智能体 Muse 对所有用户启用。已上线案例包括 Mercury 的余额查询与受审批规则约束的转账，以及土耳其航空的票价、航班状态查询。

对企业来说，这套设计的好处是不必一次搭完授权体系。不登录也能使用一部分能力，商户可以先只发布一个发现文件，后面再按需接入 OAuth 与账户操作。Sierra 称新增 60 家设计合作伙伴，总数超过 100 家，并提供了给 Coding Agent 用的技能和检查部署是否合规的命令行校验器。

要注意版本状态。官方站点、实施工具包和 GitHub 仓库仍把当前文本标为 draft 1.0，变更日志写明在正式定稿前修复可能不向后兼容，支付通知、推送和附件也尚未覆盖。协议采用 Apache 2.0 许可。

## 主题四：Anthropic 三条线并行——上市、放量、架构公开

Anthropic 官方账号确认已向 SEC 提交包含招股书的注册声明，并提示注册声明生效前不得销售相关证券。提交不等于完成发行或挂牌；申报文件正文不在本次抓取范围内，因此发行规模、定价区间均无从核实。Dario Amodei 在纽约与 JPMorgan CEO Jamie Dimon 对谈时表示，对上市时机并不在意。

## 主题五：同一天四起安全事件，权限边界比模型能力更吃紧

Cursor 公布了事件复盘：攻击者利用 Fireworks 暴露的访问密钥，读取了用于模型训练的 coding agent trace；受影响 API 凭证的客户不足 0.01%。另一条并行线索是恶意 Claude Code 扩展波及最多 5000 名用户。Cursor 的结论是凭证轮换与扩展重装需要按各自情况判断。

Grok Build 的问题在另一层。量子位援引 Claroc 的调查称，受测地址中有 37,571 个应用在线，94.7% 无需登录即可打开，部分涉及企业资料、患者记录与明文密码。这不是模型漏洞，而是把"随机网址"当成了访问控制。截至报道发布，24 个由相关公司员工创建的应用已下线。

另外两条更接近研究阶段。微软的"Lazarus"研究称，通过改写不足十个休眠神经元即可植入智能体后门，无需重训或投毒数据，部分实验触发成功率达 98.8%——前提是拥有模型权重写入权限，且尚未观察到实际攻击活动。安全团队 GCSA 则披露，在一家头部机器人厂商的真机上通过近距离蓝牙或语音指令取得了控制权，并能驱使其进入禁区。

四件事的共同点：智能体拿到的权限范围，往往比它的判断力扩张得更快。

## 主题六：DeepSeek 把自家 App 的能力拆成 API 并开源前端

多位开发者转述 DeepSeek 的公告：联网搜索、深度思考搜索、文件解析、链接阅读、语音交互，以及 OCR、ASR、TTS 等底层能力，全部以独立 API 形式开放，可单独调用也可组合使用。官方同时开源了一套完整的聊天前端 Demo，支持导入历史对话。

这件事的方向与主流相反。多数公司正把能力收进自家超级入口以留住用户，DeepSeek 则把入口背后的组件拆出来，等于把"复刻一个 DeepSeek App"变成可执行方案。已有开发者提到 ASR 价格明显低于同类服务。

公告里的一句话解释了动机：现有对话产品只是"较为基础的一种形态"，产品背后的各项能力都可以通过 API 自由组合，官方希望开发者省掉重复的基础工作。对做垂直产品的小团队来说，这意味着不必自己接搜索、OCR 和语音合成三条供应链，但也会把差异化压到更上层。

证据边界：本次抓取的只是社交平台上的转述与截图，没有官方公告原文或定价文档，具体额度、限流和计费需要以官方文档为准。首发时间选在北京时间周五晚间，也让不少国内开发者的第一反应是"下次能不能换个时间"。

## 主题七：开源工具链一天补齐了三个缺口

llama.cpp 发布 v1.0.0，这是这个最常用的本地推理库的首个完全稳定大版本。Clément Delangue 强调的重点不是性能而是控制权：在手机、笔记本和工作站上本地运行，数据不出机器。

Chrome 团队的 Modern Web Guidance 结束预览，发布稳定版 1.0。它要解决的是编码 Agent 的训练数据滞后问题——模型会用一大段 JavaScript 重写浏览器已原生支持的动画，或者堆嵌套 div 而不使用 `appearance: base-select`。1.0 包含 200 多条经领域专家审阅的指南、Baseline 兼容数据与回退方案，并与 Firefox、Edge 团队共同维护。合作方给出的数字包括 MetaMask 在约 480 个 PR 上驱动了 43 处无障碍与语义化 HTML 修复，note inc. 的现代 Web 检查通过率从 61% 升到 94%。

阿里开源了内部使用两年的代码审查工具 open-code-review：读 Git diff，由带工具调用的 Agent 翻阅全文件并搜索代码库，输出精确到行的评审意见，内置空指针、线程安全、XSS 与 SQL 注入规则。README 自述同模型下精确率高于通用 Agent、token 用量约为九分之一。OpenAI 同期放出 Codex Security 的命令行与 TypeScript SDK，覆盖扫漏洞、验证、生成补丁并导出 SARIF/JSON/CSV。

同一批上榜项目里还有两个方向。Tailscale 的 tailcat 像 netcat 一样在机器间开 WireGuard 端到端加密隧道，自动打洞直连，不需要账号也不需要 root；Chrome DevTools 官方的 MCP 服务让编程 Agent 直接操控真实 Chrome，录性能 trace、读控制台、截图，Agent 不必再盲写前端。

这几个项目指向同一个变化：大厂开始把内部工程规范直接喂给 Agent，而不是等 Agent 自己从公开语料里学。

## 主题九：三份评测同时出现，"分数"本身开始需要说明书

Anthropic 公开了安全评测方法，出发点很直接：说一个模型"比上一代更安全"，依据只能来自某套评测，评测本身不扎实，结论就站不住。他们放弃用拒绝率衡量自杀与自我伤害场景，改统计"恰当回应率"——用户正处在危机中，模型不回应本身就是失败；多轮对话中只要一轮不合格，整段不通过。

最值得注意的是配置差异。同一个模型在 API 上的原始形态，与加了系统提示的版本，多轮恰当回应率最多相差 34 个百分点；系统卡里自杀与自我伤害多轮评测正好是这个差距，API 为 60%（±14%），带新系统提示后为 94%（±7%）。他们举的反例同样重要：恋爱诈骗评测中 Opus 5 得分 98%、Opus 5.5 得分 94%，但差异统计上不显著，不能据此判断谁更安全。

投资研究侧的发现更尖锐。BuySideFlow 收录 408 项中文投资研究任务，九种智能体配置准确率在 16.2% 到 36.8% 之间；对 100 项共同任务的 900 次运行审计发现，通过结果检查的 380 次里有 193 次违反时点约束，占 50.8%。也就是说，答案自洽不等于使用了当时已披露的数据——这类错误靠结果比对查不出来。

医疗与记忆两侧提供了同类提醒。MedGPT 在 40 例未公开疑难肺癌病例上平均 85 分，250 名三甲医生平均 53 分，但这是答卷评测，不是临床结局比较。CAMP-II 用普通文件操作训练长期记忆，报告的是相对最强 OPD 基线 2.97 倍的增益，而非总成功率；记忆行为迁移到 Terminal-Bench 2.1 与 SWE-Bench Pro V2 后提升任务成功率。Anthropic 给出的操作建议是报告里写清模型版本、提示词与评分器，不要跨评分器直接比较数字。

## 主题十：具身智能的两端——长程操作有了演示，三维内容有了入口

Jim Fan 发布了一段 GR00T 2 的演示：视频中模型控制真实灵巧手端到端完成化学实验并清理现场，画面为未剪辑的一倍速，任务包含二十余个步骤、持续五分钟以上。帖文同时介绍从人类可穿戴设备与仿真数据向机器人迁移的方向。单次演示不构成泛化验证，但长程任务的完成度比常见的单动作展示更接近可用性判断。

## 编辑结论

今天真正变化的不是某家公司的排名，而是三件事同时到位：算力供应商的领导层被资本结构反噬，前沿实验室开始交付需要机器逐行验证的研究成果，智能体拿到了钱包、身份协议和企业权限。前两件决定了这轮投入能不能持续，第三件决定了出错时谁来负责。英伟达周二发财报，Kress 是否延续此前的芯片路线图、董事会有没有给出寻找正式继任者的时间表，是最近一个可以验证的观察点。
