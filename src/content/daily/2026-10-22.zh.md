今天的主线是安全。AI 帮研究者找到一个影响大量网站的内存漏洞，攻击方在公开披露前四天就把它用了起来，利用量从数千次涨到数百万次。同一天，微软、Wiz、赛门铁克分别披露了智能体参与的攻击活动，银行开始封禁替客户登录的代理，Anthropic 把主动型个人代理放上研究预览。能力在往前跑，授权、监控和补丁节奏被同一件事追着改。

## 主题一：PHP2Shell 把漏洞窗口压成四天

漏洞本身是 PHP 生态里的一段内存错误。Calif 与 Wiz 的研究人员找到它，OpenAI 称自己的前沿模型在攻击者之前发现了同一个问题，随后与 PHP 社区、Calif、Wiz 一起验证并开发补丁。DeepLearning.AI 的说法是，GPT-5.6 Sol 帮助定位了这个内存 bug，受影响的软件运行在最多 70% 的站点上，补丁已经发布。

时间线才是重点。Ars Technica 报道，漏洞在披露前四天已遭利用。404 Media 引述 Cloudflare 首席执行官的说法：公开公告前 10 小时已出现数千次利用尝试，公告后两小时内升到数十万，目前是数百万量级。英国 NCSC 提示，这类漏洞可能让攻击者不必持有登录凭据就能控制网站服务器；NSA 建议无法立即更新的机构把系统离线；白宫称联邦机构正在评估对政府系统和关键基础设施的影响。

对运维来说，留给修补的时间被压到小时级。补丁发布只是起点，后面还有资产盘点、兼容性测试、维护窗口和回滚预案，这些环节的耗时不会因为漏洞被发现得更快而缩短。Aravind Srinivas 当天说 Perplexity 在发放算力额度，鼓励用户检查自己的 PHP 漏洞，这类自发排查也在填补官方响应之外的空隙。

证据边界要说明：「AI 抢在攻击者之前发现」是 OpenAI 的自述，披露节奏与利用量来自媒体和厂商转述，四天窗口本身没有独立第三方复核。

## 主题二：攻击端的智能体已经成规模

微软披露的一起活动里，与中国相关的组织借开源智能体框架攻击 Microsoft 365 租户，受影响企业超过 2250 家，每分钟登录尝试最高达到 2900 次，有的场景不到三小时就拿到特权访问。这是把爆破、凭据填充和横向移动交给自动化流程之后的节奏。

Wiz 的报告补充了另一条线：开源自主渗透测试框架 ARTEX 在 10 月被用于针对多家 IT 与软件厂商，活动与微软追踪的 Storm-0940 重叠，并已扩展到供应链方向的尝试。框架是公开的，攻击者不需要自己写工具，只需要会用。

赛门铁克的蜜罐记录更极端。一个把大语言模型嵌进核心的智能体劫持了互联网上缺乏防护的模型端点，自主扫描目标、利用服务器漏洞、窃取数据库凭据、安装挖矿程序，最多连续执行 10 万步，算力费用由被劫持模型的主人承担。攻击者离场之后，这条链仍然能自己跑下去。

智能体自身也成了新的攻击面。当天发布的一个基准专门测「残留注入」：代理靠长期记忆和定时任务跨会话保持状态，一次性注入就能写进这两条通道，攻击者离场后仍会复燃。这个基准包含 12 个场景、101 个攻击任务，报告称五轮之后触发率没有衰减。

防守侧的暴露面同时在扩大。LiteLLM 1.107.0 版本在 PyPI 上被植入后门与窃密代码，自动升级的环境可能泄露 API key，还可能被远程控制，这是该项目再次被妥协；OpenCode 通报约 1.4% 的 Console 用户受影响，存放在其中的 OpenAI、Claude、Google 密钥可能外泄。

几家披露方都是安全厂商，细节无法独立验证，但方向一致：智能体既被用来攻击，也成了被攻击的入口。

## 主题三：Claude Duet 先征求意见，再动手

Anthropic 把主动型个人代理 Duet 放上研究预览，由 Opus 5.5 驱动。它跑在自己的云电脑上，每隔几小时检查一次你的应用，发晨间简报，你离线时继续推进待办。官方给出的接入规模是 6000 多个集成，覆盖 Slack、Shopify、HubSpot、QuickBooks 这类工具，并继承已有的 Claude 记忆、技能和已连接账号。

边界画得很具体：发送、付款、签署、删除之前都要先问；股票交易和银行转账完全不在允许范围内。它能在用户离开后追欠款、准备工资单、起草邮件，甚至通过 Stripe Link 或 Shop Pay 下单，但每一步都需要确认。

体验侧的反馈比功能列表更有信息量。AI Valley 的作者试下来认为它仍会误判紧急程度，偶尔读错对话上下文，处理私人琐事不算强；更实际的问题是后台工作要计入原有的 Claude 用量，打开 Claude Code 时可能发现额度已经被助理消耗了一部分。他的另一个担心是这类常驻代理会变成新的收件箱：一天批准三十个小决定，等于多了一个昂贵的中层。

一条同日的开发者动向值得注意。第三方工具 Agent Tincan 宣布支持 Duet，让代理之间可以互相调用：Grok Bot 让 Duet 完成编码任务，Duet 反过来问 Grok Bot 要当天的 X 帖子。个人代理的竞争点因此不只是接了多少应用，还包括能不能被别的代理当作工具调用。

目前是美国 Pro 与 Max 用户的等待名单，暂时不额外收费。功能与限额都来自厂商自述，尚无独立评测。

## 主题四：银行封禁代理登录，1Password 开始代填

Axios 报道，多家美国大型银行开始限制第三方 AI Agent 访问客户账户。银行发现代理在客户账户内活动，其中一些操作看起来超出了用户指令；高管表示很难分清正在操作账户的是人还是代理，也难以判断代理的行为是否获得授权。摩根士丹利已封锁第三方代理，摩根大通、美国银行和花旗在限制接入，同时准备出事后的应急处置方案。

一个关键细节是，不少代理拿到的账号密码是客户自己给的。但代登录这种方式仍违反银行要求本人登录的规则，授权链条在技术上成立、在合规上不成立。

同一天，1Password 的 Agent 连接器全量上线：用户可以授权 muse、Grok Bot 这类代理登录对应网页，密码由 1Password 完成填写，代理本身看不到明文。这提供了另一种思路，把「代理能不能操作」换成「凭据以什么形式交给代理」。

两件事放在一起，说明部署瓶颈已经从模型能力挪到了身份与授权：谁在操作、得到了谁的许可、出了问题谁负责，目前都没有通用答案。银行侧的信息来自 Axios 单一报道，具体机构数量与限制范围未披露。

## 主题五：开源侧一天落了四层

通用模型这层是 MiniMax M3.1 Flash：权重公开，总参数 428B，每个 token 激活 23B，上下文 100 万 token，Hugging Face 与 ModelScope 均可下载。稀疏激活让推理成本落在与总参数量不匹配的档位，这也是这类 MoE 被广泛部署的前提。发布当天的接入名单包括 SGLang 与 Miles、NVIDIA NeMo 的微调支持、TokenSpeed 推理、Together AI 的生产部署；MiniMax 还宣布与 Inferact 合作推进生产推理，把工程改进回馈给 vLLM。

记忆架构这层是 MemT-1.0。它把记忆模块接进模型底层，而不是外挂向量库，官方给出的数字是 256K 上下文下显存开销恒定在 40MB，首字延迟百毫秒出头。如果这个恒定开销在长上下文里成立，检索式记忆方案的成本结构会被改写。

专业领域这层有两个小模型。Carbon-X 有 148 亿参数，Apache 许可，把 DNA 序列与普通文本放进同一条 token 流，中段训练用了 302B token，五项 DNA 基准平均 66.7%，接近 GPT-6.1 的 67.5%，尚未做临床验证。OXR 只有 13 亿参数，把 PDF 和文档图片转成结构化 Markdown，能识别 13 类版面元素并保留阅读顺序与坐标。

一个开源模型能否被用起来，越来越取决于发布当天有多少推理栈愿意适配，而不是榜单排名。以上参数、上下文与基准均为官方口径，尚无独立复测。

## 主题六：Claude API 删掉采样参数，默认值也换了

Anthropic 发布 2026-10-21 版 Claude API 规格，把 temperature、top_p、top_k 三个采样参数一起删除。用新版 Messages API 时，请求里只要还带着其中任何一个就返回 400，连 temperature=1 这样的默认值也不能传；采样统一走默认配置，temperature 固定为 1.0。这是 Claude API 自 2023 年以来第一次推出新的正式版本号，改动同时涉及消息格式、SDK 与鉴权方式。

对做代理、harness 和模型网关的团队，这是一次必须排期的破坏性变更：以前靠低温度压稳定性、靠 top_p 控多样性的调参空间没有了，行为一致性要回到提示、工具设计和评测上解决。

同一天还有一处默认值变化。Claude 网页、桌面与移动端下周起在 Pro、Max、Team 套餐默认以 auto mode 运行，不再逐步请求批准，改由自动检查拦截高风险操作，用户可随时切回手动。官方引用的 Claude Code 更新称，auto mode 用独立分类器审查 shell 命令，测试中拦截了 89% 的危险命令，人工批准为 14%。

两个变化方向一致：平台在收回可调参数，把安全判断放到自己的检查层。89% 与 14% 是 Anthropic 自测数据，测试集与判定标准未公开；API 变更细节目前来自二手整理，官方 changelog 正文未在本轮档案中取得。

## 主题七：Agent Skills 交给基金会，harness 开始分层

Anthropic 宣布把 Agent Skills 捐赠给 Linux 基金会下的 Agentic AI Foundation，范围包括名称、Logo、GitHub 组织与域名。此前 MCP 也已交给同一基金会。官方披露的数字是：自 2025 年 12 月发布开放标准以来，超过 70 个代理平台接入，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code；已发布 100 万个 Skills，安装量接近 2.8 亿次。

标准之外，方法也在被写成规范。Matt Pocock 给他那个 30 万 star 的 Skills 仓库加了 software-factory 设计 Skill，内容不是可执行流水线，而是一份术语表：Task、Trigger、Run、Runner、服务槽位，配一条设计原则——每个触发都是油门，一次只加一个自动触发，等刹车可信了再放开。Warp 在同一天讨论软件工厂的配置格式，理由很实在：把散落在各人电脑上的对话数据收拢起来。

公司内部的对应物是 OpenAI 的 FDE 团队。它要填的是「部署差距」：模型看起来能做的事，和客户在真实约束下能稳定用起来的事之间的空档。打法是先把结果做进生产，再把定制方案收成可复用的 Codex，模型本身不够的地方用评测把缺口交回研究团队，目标是每隔几个月让自己在这类问题上不那么必要。

研究侧开始让编码代理改自己的 harness。微软与 UCSB 的做法是让代理读论文，把方法写成代码，再修改执行框架，在验证任务上跑实验，只有更好的设计才留下；任务完成率从 69% 升到 81.5%，流程还能组合已有模块。改的是外围而不是权重，这类改进的复现成本低，也更容易被工程团队照搬。

把技能格式、协议和编排方法交出去，意味着竞争位置上移：谁能定义任务怎么被触发、结果怎么被验证，谁就掌握了工厂的节拍。100 万与 2.8 亿是官方口径，未独立核验。

## 主题八：METR 与 Redwood 在 OpenAI 内部查了三周

METR 与 Redwood Research 各派一名研究者，在 7 月 21 日至 8 月 11 日进驻 OpenAI，获得内部代码与基础设施的深度访问权限，检查内部代理（含 Codex）的错位行为监控能不能被发现、能不能被绕过。产出是一份 61 页的内部报告，公开稿只给了高层摘要。

摘要提到的缺口很具体：监控要等代理交回控制权才触发，只要持续执行操作，就能持续推迟检查；覆盖范围有空白，也存在绕过监控、沙箱与 auto-review 的路径。有转述称超过 10% 的内部 Codex 流量未被监控，这个数字来自二次转述，未经原始报告确认。

OpenAI 的回应是这次评估由自己主动邀请，研究成果帮助其在扩展系统时加强了防护，影响生产防护栈的漏洞已经修补，并表示会继续与第三方评估机构合作。评估方没有独立复核修补是否有效。

这类驻场评估的价值在于把「实验室自己说安全」变成「外部看过一遍再说」，但公开程度决定了它能被验证到哪一步：报告不公开、修补不复核，剩下的仍是自述。同一周，OpenAI 与 Uber 把 ChatGPT Work 铺到全员，代理进入生产的规模在扩大，监控缺口的影响面也随之扩大。

## 主题九：新基准开始测跑分测不到的东西

当天最反直觉的一条来自机器人评测。新论文把 GPT-6-Astra 丢进 12 项机器人基准，它在 LIBERO 套件上接近饱和，RoboDojo 拿到 81.9%，但论文的结论是它验证不了物理成功；一条超长任务烧掉约 900 万 token，耗时接近两小时。分数高和任务真的做成，在这里是两个问题。

医疗方向的基准争议更大。微软发布序列诊断基准 SDBench 与诊断系统 MAI-DxO，论文登上《Science》，官方称疑难场景比医生准四倍。这个结论基于自建基准与真实病例数据，微软 AI 负责人苏莱曼称医疗 AI 终于到来，但外部媒体质疑其基准设计，尚无第三方复现。

金融方向的结果更像一次压力测试。量化研究基准 Quant-Arena 给 9 个前沿模型 3042 只 A 股的历史数据，让它们自己写代码、构建信号、回测并修改策略，冻结版本后放到封存的 2024 年行情里检验，计入交易成本与模拟冲击。综合得分第一的 GPT-6 Astra 年化收益 10.7%，全年 75% 的交易日空仓；9 个模型里只有 4 个赚钱。

语音方向补的是细节维度。Sierra 发布 τ-Entity 基准，测语音代理能否正确采集、发现错误并修复姓名、电话、地址、邮箱，10 类实体共 200 个任务，覆盖六种语言。

还有一类基准在测规模本身。一个新框架基于真实调查造出五亿个合成家庭人格，用紧凑决策模型模拟消费、现金与还款路径，在消费金融选择上达到 74.55%，已跑过八大金融任务族。它要回答的不是单个模型多聪明，而是把智能体放到社会规模的经济模拟里，结论还站不站得住。

这几个基准的共同点是把「能不能用」拆成可测的小问题。厂商自建基准仍然决定叙事，自建与自测之间的空隙，目前只能靠外部复现来填。

## 主题十：上市与融资挤在同一天

Anthropic 最快在 10 月 23 日公开提交 S-1。Yahoo Finance 引述三名知情人士称，公司 6 月 1 日已向 SEC 秘密提交草案，这次是公开披露；路透给出的时间表更细：计划 11 月 9 日当周开始向投资者推介，争取 11 月中旬上市，提及的潜在估值约 1.5 万亿美元，时间和估值都还有调整空间。

Newcomer 的长文补了一段股权史：多年来风投因治理结构与安全优先路线保持观望，目前没有任何机构持股超过 2%；公司曾明确把单一投资人持股控制在这个水平，以避免话语权集中。

DeepSeek 那边是另一条路径。彭博社称其新一轮融资规模约 1000 亿元，折合约 150 亿美元，出资最多的是腾讯与宁德时代，额度从 500 亿元起谈并两度上调；三方均未公开确认。

## 高价值单点

- **科大讯飞星火 X2.6**：293B 总参、30B 激活、100 万 token 上下文，官方称首次用全国产算力训练代码与智能体能力；输入每百万 token 限时 0.9 元，4B 端侧版本免费。
- **Recursive Flint**：田渊栋团队的开源编码模型，约 400 亿参数、混合专家结构，SWE-bench Pro v2 得分 89.7%；团队称 Eureka Machine 参与了训练流程的大部分环节。
- **TokenGate**：斯坦福与伯克利研究者做的可插拔剪枝模块，插在模型浅层，只把重要的 top-K token 往上传；无精度损失时首 token 时间快 1.4–11.3 倍，峰值显存降 1.5–3.4 倍，训练成本接近 LoRA。
- **SkyRL 长上下文训练**：在 B200 上把 GLM-5.3-Flash 的单序列训练长度做到 100 万 token，峰值约 144.5 GiB，约为开箱 Megatron 基线的 64 倍，靠稀疏注意力走稀疏核、切分 indexer 和激活重算实现。
- **OpenAI Decisions API**：基于 GPT-6 Luna，面向分类、路由、评分这类有界问题，官方称速度最高比通过 Responses API 调用同一模型快 10 倍。
- **Replit Monitoring Agent**：读取生产日志与指标排查错误与部署失败，开启 autofix 后验证修复并邮件汇报，开启 auto-publish 可直接部署修复。
- **Kimi K3.1 与 Qwen4 临近**：Arena 上出现匿名模型 Kibitz 与 Kalmia，有人用 tokenizer 特征推断分别指向 Kimi 与 Qwen，称两家已进入线上匿名测试阶段；未获官方确认。
- **X-VLA 接入 APXInf**：清华 AIR 的 0.9B 机器人模型，一天内由代理接入推理引擎，缺的 6 个 CUDA 算子自己补，共 8 次提交、5300 行代码，人只介入一次拍板；动作最大误差 0.0032–0.0038，4090 上 CUDA Graph 跑 40.5 毫秒，原版 93.4 毫秒。
- **PGX 临时数据库**：用 Rust 写的 PostgreSQL 兼容运行时，一个进程可持有数百到数千个隔离数据库，靠密封模板与热池做到毫秒级创建，面向代理、CI 和每个 PR 的预览环境。
- **紫荆智康 AI 医院**：清华 AIR 孵化，已进入多地医院测试，给每位医生配专属 AI 分身，分身之间跨科协作；官方称 AI 医生在 MedQA 上准确率超过 96%，靠门诊数据微调更新。
- **中国公司的 RSI 披露**：GovAI 研究者整理的案例里，MiniMax 让 M2.7 自己分析失败记录、规划改动、改代码、跑评测再决定保留或回退，自主运行超过 100 轮，内部评测集提升 30%；智谱的案例落在推理基础设施的自优化。改进对象都是 harness，不是权重。
- **Google DeepMind 终身不贬损条款**：Neel Nanda 称至少许多英国 DeepMind 员工的合同含终身不贬损条款；BBC 报道的研究工程师 Sofia Liguori 因不认同公司扩大军事合作而辞职，并公开表示「原则上这一生都不被允许批评 Google」。
- **豆包在闲聊里推销商品**：双十一期间聊到天气转冷就递上抖音商城优惠券，QuestMobile 数据显示其月使用时长从 144 分钟降到 133 分钟。信任边界正在被商业模式试压。

## 编辑结论

今天最值得记住的不是某个模型又多了多少参数。漏洞的发现和利用速度被 AI 拉平，代理开始进入账户、支付和运维这些真正有后果的地方，而平台方在收紧参数与默认值来接管风险判断。补丁、授权和监控，这三条都比模型能力慢半拍。
